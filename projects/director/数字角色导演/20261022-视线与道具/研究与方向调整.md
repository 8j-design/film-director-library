# 研究汇合与训练方向

2026-10-22。用户补充数字影像与动画的侧重，并授权分子 agent 研究、阶段审查后继续推进。编剧核心训练继续，导演训练接到可执行的数字表演和角色设计。

## 这次调整到哪里

人物分析仍问欲求、关系、策略与后果。实施时优先产出角色行为设定、视觉工作版本、关键姿态、定时分镜或粗模表演。真人选角与到场排练不再作为当前必须完成的前置项；需要时可取动作、身体或声音参考。二维、三维和生成式影像都可以承接，用户没有把AI设为唯一制作方式。

“角色形象定稿”分两件事：保留身份、比例、服饰等识别结构，同时检验这个结构能否完成故事要求的转头、抓握、遮挡与形变。人物的心理也不因一张小传而锁死；在新场景出现矛盾时，允许修改行为解释或版本。没有眼睛的抽象角色，则用朝向、节奏、距离或形变组织注意，不强制套人脸表演。

## 资料落实到什么选择

[於水访谈](https://www.chinawriter.com.cn/n1/2023/0310/c405057-32640746.html)说明角色与事件可在创作中互相形成，也描述阶段反馈。本项目据此先写和试演，再修人物解释；不把一个导演的习惯定为唯一路径。

[Ed Hooks作者文章](https://www.awn.com/blog/acting-vs-moving-illustrations)讨论行动、目的与障碍；[Dana文章](https://www.animationmentor.com/blog/10-advanced-acting-performance-tips-for-animators/)关注思考变化和主要姿态。用于把“表现不愿意”改写成“保留纸样，令对方暂时停下收走”；不是要求每句台词都配一个姿态或固定停顿。

[Disney视觉开发](https://www.disneyanimation.com/process/visual-development/)与[Layout流程](https://www.disneyanimation.com/process/layout/)将设计、场面、角色、道具和镜头连在一起。本次先检查接触关系和可见信息，再决定是否细化造型。官方流程不是已对本项目作出的效果保证。

原图中的五姿态观察只涉及识别要素、姿态与乐器的变化，不视为连续动作或成片研究。Blender三项入口本次返回402，全部保留为未读，不把检索标签或简介升级为课程完成。

## 阶段之间怎样继续

阶段审查集中在准备制作、预演完成、接续前后场三个节点。每次给出产物、实际发现、改动及剩余问题；一般构图、动作或资料问题自行处理。涉及实质创作方向缺失、新支出、权限或用户必须决定的取舍时再问。当前没有需要用户重新找资料或到场排练的阻塞。

多 agent 用来发现差异与反证，不用多数票给艺术下结论。批评必须指向具体版本；看过文字、图、动态片段分别注明。这里没有创建定时任务，也不把当前执行描述为聊天结束后仍自动运行。
