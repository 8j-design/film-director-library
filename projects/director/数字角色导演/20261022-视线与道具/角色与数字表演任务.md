# 角色与数字表演任务

2026-10-22。《借桌》人物沿用陈建、孟雨。当前为虚构工作练习，新增纸样抓取与纸摞细节；修包工艺与最终风格没有实地或制作验证。

## 角色形象工作版本

| 层次 | 陈建 | 孟雨 |
| --- | --- | --- |
| 当前需要 | 保住眼前还在使用的工作材料 | 清出桌面，继续准备门外活动 |
| 关系压力 | 想留住使用权，也不愿马上把人赶走 | 希望加快进度，也不愿承认自己又得回去让别人等 |
| 可试的策略 | 先控制纸样；或把对手纳入当前工作 | 先收零散纸；发现阻力后改找别的办法或帮忙 |
| 不能从身份推出 | 年长不等于迟缓、固执或体弱 | 年轻不等于莽撞、无经验或只会看手机 |
| 仍缺的证据 | 同一需要在另一段压力中的选择与代价 | 对活动参与者的主动安排；她不能只负责响应陈建 |

几何模型的两个颜色仅用来追踪身份。角色年龄、脸型、服装或身体比例没有在此作审美定论。下一步真正做造型时，保存必要转面、识别点、表演范围、手与道具尺寸、允许形变和相邻镜头状态；按戏的需要筛选，避免机械产出一大本设定集。

## 本次预演要执行的任务

陈建：在孟雨将最后一张纸归入纸摞前，把这张仍要使用的纸样留在桌上。孟雨：把桌面零散纸收起，为挪桌创造条件。两人目标只在这一张纸上暂时相撞，本段不决定谁有理或全场怎样和解。

| 时刻/节点 | 可执行动作 | 接收信息与道具状态 |
| --- | --- | --- |
| 0—2秒 | 孟雨另一手有纸摞，主动手伸向纸样右边缘 | 纸样在固定桌面上；陈另一手仍在尺附近 |
| 3—4秒 | 陈主动手从身前移向纸样，掌面覆盖纸样中部 | 不是凭表情命名为愤怒；看手、接触和对方反应 |
| X：3秒起 / Y：4.7秒起 | 孟主动手沿同一路径撤回 | X保留同步/预判的可能；Y保留看到后改变的可能，不预判优胜 |
| Y′ | 时间和手部与Y相同，只把孟的注视目标改向门口 | 若仍作相同眼神交流解释，说明分析过度；也允许她注意外面的解释 |
| 6.3—10秒 | 手部恢复到各版共同的结束位置，陈保持掌压 | 只完成一小段状态，不替接下来的角色选择下结论 |

秒数仅是本次比较参数，不是人的思考或动画的统一公式。X/Y的手部路径、幅度、人物比例、机位、纸样位置和总长相同；撤手相位不同造成停留时长变化，这是实验内容而非隐藏补偿。Y′的注视目标另作变量。

## 具体制作约束

- 观看层去掉视线射线、情绪词、故事解释和音乐。审查层显示目标与时间；角色姓名可帮助追踪身份。
- 陈用扁平掌面，孟用夹取边缘姿态；固定纸样不被凭空换手。另一手的纸摞补充“正在收拾”的上下文，但不能据此证明观众读懂全部动机。
- 修改版采用二连杆几何约束，避免手臂随位置任意伸长。这不是完整绑定、受力、重心、布料或三维碰撞测试。
- 角色声音、口型、微表情后续按所需镜头加入；本次静音旨在暴露动作信息，不把无对白设为全部作品标准。

当前可检查的是时序、接触姿态与注视差异。保护工作、敌意、求助、善意等人物解释仍需前后动作与观看反馈支持。
