# 《Pas de deux》全片范围抽样静帧核看：时间复制、双人接触与当前试作的区别

2026-10-24。本报告为知情研究：已知影片作者技术说明，也已读《最后一张》的制作前提和V1/V2问题记录；不冒充不知道创作意图的盲读。只研究本次实际取得的NFB网络版本，不把奖项作为视觉质量分数。

## 3. 从实际图像能推进的分析

### 3.1 两位舞者，与同一身体在时间中的复制，是两条轴

03841的一组身体轮廓、11521展开的肢体扇面，与07489左侧另一种体貌、背身的大人物，不应使用同一套“人物数量”读法。前两者主要提供同一身体不同姿态并存的图像证据，后者连同后续两种体貌相接的样本，支持两位真实表演者的关系轴。由于已有作者技术笔记，可以把前者解释为时间叠印；仅从一张低分辨率静帧则不能逐份认出其确切曝光顺序。

这使比较问题更精确：我们既要问“谁与谁形成关系”，也要问“画面怎样把一个行动的先后组织成可见形状”。不能把复制像当增加角色，更不能把当前试作两名合作者的接触错误解释成时间艺术。

### 3.2 清楚形体与融合图形都有位置，不能只截一张最复杂画面

10561的密集身体群、11521的扇面，与11713附近较单纯身体、19009两张清楚侧脸，在样本顺序中并存。全段不是“越来越多残影”的单一配方。清楚的身体提供识别参照；层叠时，观看对象可从“哪只手做了什么”转向群像的方向、密度与弧形。这里对“功能”的描述是研究解释，不声称已测到观众必然这样看。

一个反例很关键：当白线融合，局部解剖信息确实可能减少；它仍可能形成有用的图形，并不因此自动失败。但《最后一张》若在必须读懂“托住同一包、放稳、撤手”的位置丢失手—物关系，就损害了它自己冻结的任务。参考片允许的模糊范围不能直接移作我方免责条件。

### 3.3 黑背景、边缘光、负空间服务于这套材料，不能只借画风

多个样本中，身体内部暗、周边轮廓亮，黑场没有工作室式的门窗陈设。07489较大的左前方身体与右侧较小形象可以同时辨认，空白也让多份手臂有展开余地；10561、18049等重叠处则有白线并为白块、相邻肢体难分的情形。这支持“轮廓条件影响复制后的可读性”，不支持从JPEG反推实际灯具位置、亮度比和每处曝光参数。

对我方可迁移的是检查物体与背景的明度／轮廓关系、关键手势附近是否留出可读空间。不可直接迁移的是把版画工作室清成黑舞台，消去本来需要承担“共同生活和清空”证据的私画、箱、钥匙、桌和门。

### 3.4 接触姿态是可见证据，承重和连续控制还需要另查

09985可见两人间伸出的手／前臂汇合；12865可见后方身体与前方人物腰侧交叠；15937与18049可见腰臀／腰侧附近的手和伸展身体。它们比抽象的“合作”标签具体：接近、身体朝向和接触位置可在图像中定位。只是手指细节小，有时复制轮廓也交织；没有足够连续帧便无法验证某个手掌是否始终贴住同一部位、何时开始承重、谁主动回应谁。

因此本报告不以舞者姿态宣称做过力学验证，也不据一张漂亮托举姿态判定整段动作成立。反查我方时同样应避免“截图两手碰板，所以搬运已通过”的跳跃。

### 3.5 裁切需要按任务判断

04801、18049的身体有部分越出画框，但在实际段落样本中，前后也有全身与两人关系的参照；近画面可以把注意集中在躯干、手臂和重复形体。它提示不能把“必须每镜都看见全身”定成普遍准则。我们没有完整连续观看，仍不能断言这些裁切如何在每次剪接中工作。

这也不能倒推旧空衣展示小样0.9米的固定相机视野裁切是成功构图：那个问题属于屏幕、观看点与相机视场的展示适配；本片这些样本属于源画框内的构图。两种裁切的发生层级和待解决问题不同，人能转头也与固定相机取景不同。

## 4. 原作者笔记怎样约束解释

复用此前实际选读的 [McLaren技术笔记](https://www3.nfb.ca/archives_mclaren/notech/NT_EN.pdf) 中“Technical Notes on the Multiple Image Technique of Pas de Deux (1967)”印刷页44相关正文；本轮没有重新取得整本PDF，也不称通读。此前可读检索正文说明：白衣黑场，主要以48fps拍摄；光学印片阶段把同像延迟重复曝光，延迟量控制间距，可通过停／冻使像汇合；试验认为背光有助于减少复制后的混乱。这是作者所述制作方法，**不是从本次静帧独立测出的设备或参数**。历史拍摄／放映速度也不等于目前网络文件fps。

静帧确实出现单像、分离像、扇面与汇合团簇，因而与上述方法有具体对应；但没有逐帧分析就不在任一图上标“恰为11次曝光”或给每份像分配延迟帧数。制作笔记解释了一套可调机制，不能代替对成片每次变化的观看。

旧空衣小样的已核范围主要是静帧和虚拟展示适配，不能据它证明形变传力、运动节奏或声音关系已经成立。本片的抽象运动也不要求变成完整人物故事；但它有明确的身体材料和时间处理机制。当前试作任务已经冻结为两位版画合作者及共同长纸，不能以“实验片允许抽象”为由换回没有人物接触任务的空衣方案。

## 6. 具体迁移尺度与仍未补上的缺口

最有用的迁移是**先有清楚关系参照，再允许局部信息改变；每种变化都要知道在改变身体、物件、时间还是展示条件**。对我方下一轮，可先只做一个共同抬包片段的密帧检查，连同起手、落稳和释放；再查纸到包的同物件状态链；最后查两人带私箱离场。它们直接对应现有失败，不要求加一层新特效或重建全部风格。

不能直接迁移：把13分多钟作品的展开比例压到60秒；把舞蹈托举换算成刚性长包抓握；把光学时间复制当成新角色；把黑场与背光当通用美术答案；把画框裁切当成展示视野不足的辩护；以抽样图像替代连续动作和实听检验。当前《最后一张》仍为**60秒、24fps、六节拍，V2增钥匙插入机位**，旧48秒暂拟已失效，参考片时长不构成我方通过标准。

本轮确实从“片目／技术文字”推进到“全片范围103张静帧与10张关键帧实看”，可定位复制、两人关系、景别／轮廓／裁切及局部接触的差别。尚缺正常速度完整视听、关键接触窗口的连续密帧，以及真实《最后一张》修订输出的同类复验；尤其不能评价未听到的音乐、音画同步、运动速度体验，也不能替修订作品宣布通过。
