# M《飞屋》P2 清晨空字幕与声轨测量

此前 1600–1604 秒的逐秒截图里没有正文，1603 秒附近可见眼镜旁的青蛙。此轮在同一版本本地片源核验哈希后解码 1598–1616 秒的混合音轨，转成 16 kHz 单声道 PCM，按 0.5 秒测峰值与均方根电平（dBFS）。 [M 的原发布](https://www.douyin.com/video/7632623213981322536) [清晨画面笔记](M飞屋P2清晨唤醒与凯文身份-20261107.md)

| 片内区间 | 实测和旧证据 |
| --- | --- |
| 1598.0–1600.0 | 四窗平均能量约 −53.23 至 −49.00 dBFS，均有非零波形。 |
| 1600.5–1601.0、1602.0–1602.5 | 两处分别为 −29.83 和 −28.68 dBFS，夹有较低电平的半秒窗。 |
| 1603.0–1603.5 | 均方根 −24.56 dBFS，峰值 −0.61 dBFS。同段旧画面在眼镜旁见青蛙。 |
| 1604.5–1605.0 | 电平再升至 −24.25 dBFS。旧机器语音索引把清晨段的讲解首句定位在约 1604.41 秒，随后若干索引与旧字幕提到的闹钟和蛙顺序相符。 |
| 1612.0–1613.0 | 两窗分别为 −23.88 和 −24.17 dBFS。旧画面字幕有人道早安，既有中文机器索引在这一秒附近没有输出相应词。 |

1603 秒的局部峰值是优先核听点。结合前一批字幕，已经可以把“画面暂无正文”与“音轨中已有能量起伏”区分开。仍需对齐峰值与蛙的动作帧，实听确认音色、声源、声桥和音轨层次。原片声效与作者混剪音轨也需要分开。P1 的播放器续读点仍为 811.421446 秒。 [半秒测量原始表](M飞屋P2清晨声轨测量-20261108.json)
