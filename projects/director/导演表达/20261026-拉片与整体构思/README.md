## 修订怎样实际发生

- V1把原稿关系概括得过强。独立审查指出陈建从一开始就合作，不能先制造冷漠再宣称被改变。V2改为有限责任的协商和兑现。
- V2独立复审指出故事时钟与银幕时长混淆风险、三方换书未明确分配、包架/矮凳/门外架缺项。V3逐项处理，保留先前版本和审查报告。
- 虚构空间首设门0.75米，桌短边0.85米，平面穿墙；改为1.10米后本模型采样无碰撞。这个结果只支持当前模型占地条件，不能用“246个采样”替代艺术判断，也不要求未来真实场地扩门。
- 原视频片名段直接字幕与今敏访谈一致，不能继续把它保留为疑似混淆原著/电影的负面例子。取样中引用的社交帖子原文及机器翻译尚未独立确认。

审查证据：[首轮独立复审](agents/整体表达独立复审-20261026.md)、[V2复审](agents/V2复审-20261026.md)。V3为主控落实后的版本，未增加第三轮独立通过结论。
