# 原创无声动作草稿：高处钥匙

2026-10-30；本批开始已读工作区AGENTS/开始和最新配额规则，300分钟已用41%，70%立即停止，近65%不扩长批。本目录独立保存，不改主线/库。

目标：用原创几何人物和高塔横台，局部检验“人物体积不等于场面主动权”。成人在梯子上受抓扶与站脚约束，另一只手够高处钥匙；小个子在上层横台能移动，先观察/试探，再夺钥匙离开，成人必须收回空手抓扶。交付两版实际逐帧动画、编码后解码关键帧、自审修订记录；不把此测试当两位作者全系列/七位审美研究完成。

空间和动作：同一宽景保留梯子、上层横台、挂钩与出口。大个子身体保持梯下，抓扶手及脚有明确接触点，伸出另一手但距钥匙有空隙。小个子先向下看成人、再看钥匙，靠近/短暂停顿后出手；钥匙由挂点到小个子手上，随其移动至出口。成人够不到、撤回自由手重新抓栏，再下移一阶，空钩保留为后果。

可否证标准：

1. 若大个子抓扶手/脚滑离梯子而没有相应失衡，抓持约束未表现；不能只凭说明宣称受限。
2. 若钥匙不经过可见接触/离钩/持有便换位置，转手不成立；若只用静态不同姿态硬切，也不满足实际动作要求。
3. 若小个子不先观察/试探，或大小、上下关系/通路看不清，主动权依据不足。
4. 若后果只靠字幕解释，成人并未撤手/回抓或失去机会，不称完整行动链。
5. 先渲染V1，实际看编码后解码帧找具体问题；修V2后用同一动作段核对，不用技术成功自动判艺术通过。

限制：几何二维、无声、单镜头动作草稿；不使用原片形象/台词，不用图像生成API。自审不等于无先验观众测试；尚不验证真人表演、真实生物力学、成片节奏或专业能力整体掌握。
