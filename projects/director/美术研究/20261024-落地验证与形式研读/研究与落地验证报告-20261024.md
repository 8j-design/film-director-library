# 美术研究怎样变成影像表达：研究、实作、修补与对照

2026-10-24。原44题保留为导航；本报告是一批实际研究与验证，不是44题或整个美术研究结项。下文的练习《最后一张》由助手自拟，服务能力检验，不是用户的新剧本、立项作品或已定画风。

## 这轮得到了什么

**资料只有改变了画面选择，并经实际结果反查，才开始转成创作能力。**本轮做出两版六格叙事板，第一版暴露“共同物件提前出现、前后身份混乱、离别只靠作者解释”的问题；对照旧学后实际修画，第二版改善了物件身份和包装过程的线索。它仍未充分区分“搬离”和“普通收工”，尺度也没有锁住，所以没有给自己一个通过总分。

同时做了一个可修改的布局辅助源。它的局部修改确实可追踪，但与图板指令用了不同尺度；再次比较后实际修补了提案尺寸，保留所有旧版本。这个发现说明：各份文件分别自洽，还不等于它们能交给下一环节一起制作。

修后对照《Negative Space》的作者过程材料与3张官网剧照，以及《Father and Daughter》的作者文字，发现更深一层差距：我们的工作室和动作仍偏泛化，物件还没有通过足够具体的使用史形成两个人的关系，空房也没有经过持续时间与声音检验。随后已经继续专题02的水墨、线形、空间与时间研读，没有停在交一张审查清单。

## 一、实际测试了什么

冻结文本是：两位合作者搬离共用版画工作室，各收自己的工具与小箱；面对最后一张长版画，共同包好并靠放门旁；两人带走私箱，房里留下共同包件，不解释以后归谁。六拍从共同空间走到无人空间，检验的是人物、物件、房间变化和画面顺序怎样共同表达。

修改前已经写下[文本与判据](测试前提与判据-v1.md)：至少读到共同工作过、现在搬离，认得同一件纸张转成包件；不要求辨认爱情/亲属/对错。不用改结尾、字幕或对白补漏。原文本没有规定完整包装工艺，“平护”来自本次视觉方案，已按反方审查纠正原先混称。

这是一段整体静态视觉开发，不是角色手势小模型。选择静态六格可先暴露信息和连续性问题，但它不提供连续运动、表演时长或声音证据。两版使用内置imagegen生成/参考图编辑，保留[初版指令](prompts-v1.txt)与[修订指令](prompts-v2.txt)；没有调用自备API或训练模型。

## 二、从旧学习到实际修画

### 第一版

原图：V1：修订前六格叙事板。见[本批原创媒体档案](媒体档案.md)，解压后可与本报告对应。

第一版的问题不在于画面不精细。前3格门边已经有一个蓝带长包，桌上却同时摊着尚未包装的蓝白作品；第4格才共同包装，第5、6格门旁包又换到另一侧。看图者无法确定它是不是同一物。结尾仍有大部分工作痕迹，普通收工的解释也成立。

另一个未给剧情的agent只看图，也独立指出了这些问题，能读到共同整理、包装和离场，不能确定长期搬离。它没有被要求复述作者答案。详见[隔离读图原报告](agents/blind_v1.md)。这是内部模型审读，不是人类观众、统计调查或用户验收。

| 已学材料与实际旧范围 | 回查后怎样改决定 |
| --- | --- |
| Bacher《Dream Worlds》出版社样章文字选读，未通读 | 不再只加统一气氛和风格词；先修跨格状态与整体信息 |
| 《Minari》美术设计Yong Ok Lee直接访谈正文，前批另看2张图 | 环境的变化须有使用与收拾依据；修改私人物痕迹和末场空位，而非仅调整光色 |
| OpenToonz实际生产流程文档，未运行 | 用纸张—包装—门旁的状态链核对身份，删除提前存在的相似包 |
| Malt/MaterialX已读官方文档，未执行 | 分开画面效果与可修改条件；不能把整板重新生成当可编辑资产，另试辅助源的局改 |

这是本研究的转用判断，并非这些作者审过本图板。旧材料帮助组织问题，最直接的错误证据仍是V1实际图像和读图报告。[《Minari》原访谈](https://www.intjournal.com/yong-ok-lee)中的人物、取景和资源取舍，也不能变成一切作品必须写实的准则。

### 第二版：确实改了什么

原图：V2：修除预先包件、增加包装中与清场线索。见[本批原创媒体档案](媒体档案.md)，解压后可与本报告对应。

V2去掉前3格门边预先存在的蓝带包；第4格让上下纸板之间露出蓝白版画；末两格把唯一包件固定在同一侧；末格增加墙面空痕和减少的物件。没有把共同包件带走，也没有增加和解剧情。

| 冻结目标 | 修后实际结果 |
| --- | --- |
| 同一物前后能追踪 | 明显减少“两件相似包”的歧义；尚未锁定跨格图案、比例和可复用资产 |
| 搬离能区别于普通离场 | 墙痕、空架和空桌增添清退依据；收工/部分搬走等解释仍成立，**未充分通过** |
| 空间变化来自行动 | 变化可见，但最强的墙画消失主要发生在第5→6格，未画谁在何时收走 |
| 纸张与包件尺度 | 纸进入包的线索更清楚；长纸仍大，门旁包仍较窄，目标尺寸没有可靠兑现，**未通过** |
| 留下共同物且归属开放 | 唯一包件留下更可追踪；不要求排除“下一趟再取”，不为此改结尾 |
| 时间、声音、可制作性 | 静态图板没有验证这些；不能由看图改进代替 |

主控实际复看V2，反方agent也交回了实看后的第七节报告。V1读图者的V2复审因实际额度限制未取得；因此没有第二次隔离读图，更没有“多位观众一致看懂”的结论。[反方全过程与V2追加审查](agents/phase_review.md)；[主控V2复看](v2主控复看与同类对照.md)。V2同时修改了多项相关内容，不能隔离出某一项的单独效果。

## 三、资料与真正落地，差在哪几层

**表达层。**“环境承载情绪”不等于有情绪的环境图。必须在角色怎样使用、收走、留下某物的过程中建立关系。当前作品为何值得两人共同处理，仍主要靠练习文本，没有充分落实成两个人独有的经历。

**材料层。**追加读纸本保护机构与博物馆正文后，纸张—衬护—外板不再只是一组棕色/蓝色形状；需核容纳、支撑和表面状态。门边竖靠只是临时提案，蓝带是识别设计，不是合格长期保存证明。馆藏保存规范也不能直接规定普通工作室人物必须怎样做。[NEDCC资料](https://www.nedcc.org/free-resources/preservation-leaflets/4.-storage-and-handling/4.9-storage-solutions-for-oversized-paper-artifacts)；[National Museums Scotland方法正文](https://www.nms.ac.uk/our-impact/national-work/training-and-guidance-for-museums/collections-care/object-packing/how-to-pack-paper-and-unframed-artworks)。具体读取范围见[补证记录](生活材料补证.md)。

**资产层。**两张生成图没有相机、几何、角色绑定、绘画图层或可分别调整的光/材质。后续用AI做视频，它们可以是构思和参考；能否保留同一角色、道具、动作与镜头关系，仍要对连续输出另验。后续用Blender等软件，需要重新建立可控制的场景、资产与摄影条件；不能把画面里“看起来有空间”当已有三维场景。

**运动与声音层。**图板省略纸板合拢、布带绕行、抬起移放是允许的表达选择，但实际镜头仍要决定这些动作怎样成立，或者怎样有意省略。末格停留和声音可能承担大部分离别感，本轮未实听或连续观看，不能全部归功于美术。

**生产与协作层。**美术板、布局、资产、镜头和预览必须对应同一版本与尺度。官方资料进一步给出重导入、外部材质引用、曝光和色彩文件的约束；文档阅读不等于软件交接已跑通。[Krita分镜文档](https://docs.krita.org/en/reference_manual/dockers/storyboard_docker.html)；[Godot导入设置](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/advanced_import_settings.html)。完整拆解见[落地差距研究](agents/implementation_gap.md)。

## 四、真正做过的辅助源修改，以及再次修补

除图板之外，实际建立[原生SVG布局](layout/space_plan.svg)，同尺展示原纸、包好、门旁留下3种状态；它只作辅助，不替代人物与环境美术。磁盘重读原源，只把最终包件蓝带改另一种深蓝，另存[修改版](layout/space_plan_pack_edit.svg)。结构比对得到86个元素、44个唯一ID，仅1个属性变化，固定对象和尺寸记录未变。数字44只是这个辅助文件ID数量，与44研究题无关。

但交叉比较发现：原辅助方案原纸160u、人物100u，与V2要求约110cm长纸相对成年人的尺度不一致。“每份都登记尺寸”并没有避免矛盾。于是主控补设测试成人170cm=100u，这个身高不是原提示词规定；实际另存[尺度修订](layout/space_plan_scale_revision.svg)，把纸改64.7059×23.5294u，外板68.7059×27.5294u，重读核比值与二维容纳，房间/人物锚点和原件保留。

这修复了**指令提案与辅助源**的不一致；V2原图仍未配准，不能把它写成生成图已按此比例修好。此布局也未渲染、未核门开启间隙/倾角、未导入Blender/Godot、未做接触或动画。它证明这个辅助源可定点修改，不证明原美术稿已分层、动作已成立。[过程、脚本与核对结果](layout/README.md)。

## 五、修后再与同类优秀作品比较

比较正式在V2保存之后进行。子agent先收集材料，主控之后读报告、实际看3张官网剧照并复核作者问答；没有把提前收集说成提前完成比较。没有完整观看这两部短片，不给完成片与六格静态板作等量评分。

**《Negative Space》：物件要被人使用，才逐渐成为关系。**本轮实际看过的平铺行李剧照首先清楚提供物件类别/轮廓，不足以单独提供亲情；街道剧照则把携箱人物放在门口、台阶和道路的具体关系里。导演访谈讲物件使用史、定格布料变化和团队协作，提供了比“纹理好看”更具体的检查。我们的版画工作室仍偏泛化，职业身份有了，个别人物的生活与行动差别弱。后续应让开场工作痕迹在收拾中有对应去向，不靠追加回忆象征或磨损贴图冒充共同经历。[导演官网与来源](https://www.tinyinventions.com/main/negative-space/)；[直接访谈](https://www.skwigly.co.uk/ru-kuwahata-max-porter-negative-space/)。

**《Father and Daughter》：空旷的作用来自整体。**作者把感情交给身体、构图、叙事、静止与空旷；它提醒我们不要只加强面部悲伤。我们的空房只是一个可见结果，尚未在持续时间里建立熟悉与缺席，不能称已达到相似情感效果。作者也区分短片与长片细节密度，不能把删物件当普遍高级风格。[2005直接访谈](https://www.robert-bresson.com/Words/Dudok_de_Wit.html)；[2016比较短长片的问答](https://filmmakermagazine.com/100613-the-red-turtle-director-michael-dudok-de-wit-on-silent-metaphors-charming-flaws-and-takahatas-influence/)。

不能照搬的也明确保留：不抄父子打包关系、巨手尺度、人生等待结构或死亡含义；不从定格作者选择推出数字绘画不适用；不把团队定格短片的条件当单人低成本。原材料、3张图逐项记录和失效条件见[同类材料报告](agents/comparables.md)。

## 六、审查以后已经继续的内容

已继续[专题02首批研读：画面里的空与时间里的空](专题02-线形空间与时间-首批研读.md)，补中国美术学院的《山水情》参与者回忆、美术馆记录与卓鹤君访谈，NFB间断动画说明/技术笔记检索选段、Animation Studies对知觉解释的批评，以及OpenToonz官方GitHub曝光文档选读。

这批形成的新判断是：留白不是空无一物；静态画面中未着墨的区域与时间中的未绘帧必须分别研究，传统笔墨外观也不等于已经解决运动化。两条路径都能反查本轮“空房即离别”的过快假定。资料中的民族风格判断、科学术语和技术泛化分别接受核查，不因它们谈经典便全部照收。此专题实际开始，仍未结项。

原题见[44题导航与本轮增补](44题导航与本轮增补.md)，源总纲未改、题目逐字保留；题量仍可增加。本轮主要推进整体转化、空间变化、道具、静态分镜、生成连续性与独立制作接口，没有把人物、摄影、光色、各种媒介和世界作品研究全部标成完成。

## 七、下一轮带着什么问题继续

本练习留下两种不同任务：一是表达上让搬离、个人痕迹和共同经历更可辨；二是制作上把图板、布局与真实可编辑资产配准，再把关键的包装—移放做进有时间的镜头。不能拿后一项数据核对替前一项观看，也不能无期限生成整板来代替资产工作。

广域主线继续线、形、空间、运动及媒介差异，下一批优先补完整作品与过程材料互证；当前未看的原片、没跑过的工程和没取得的人类反馈仍是实质缺口。没有学习完所有专题才允许创作的前置门槛，也没有把一次原型当整个制作能力通过。
