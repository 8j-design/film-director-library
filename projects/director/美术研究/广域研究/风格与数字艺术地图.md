# 数字艺术与风格研究地图：从画面发生的方式理解表现

2026-10-23。本报告服务用户要求的广域影视美术总纲。旧十题可以作为局部检索入口，不能继续充当研究范围上限。这里先建立数字影像、艺术家电影与扩展影像的交叉地图，不把美术收窄成布景，不把风格收窄成画风标签，也不把整张地图写成已完成学习。

实际完成：下列12份核心来源的正文或标明范围的选读。来源包括艺术家原文、直接访谈、收藏/展览说明、创作工作室技术说明和项目README。没有观看本报告涉及作品的完整影像、视频片段、图片或现场装置，没有运行代码、扫描或生成实验。网页提及“看见/感受”的效果属于机构或创作者表述，不是本次自己的观影判断。

## 1. 地图怎样组织：不是给作品贴一个标签

同一部作品可以同时涉及摄影测量、动画、档案、游戏引擎和装置。下面研究方向可交叉，数量不代表必须分别开同样多的课程。至少要同时追查六类问题：

- **画面与世界的关系：** 记录、变形、重建、抽象、模拟，还是把已有图像重新编排？不同形式怎样留下或消除现实依据？
- **造型与感知：** 线面、体积、色光、比例、细节密度、可读性、画面边界、运动质感怎样共同工作？这部分不能仅由技术名代替。
- **时间与声音：** 累积、擦除、循环、节奏、同步/反同步、生成、等待、反馈与突变怎样成为结构？
- **材料与运行机制：** 纸与颜料、电信号、像素、压缩、点云、规则、数据、模型、引擎分别改变哪些决定？
- **观看与参与：** 单屏电影、多屏、投影、现场表演、实时模拟、VR与网络版本分别允许观众做什么、漏看什么？
- **历史与立场：** 取用谁的材料、身体、文化和档案；谁获得解释位置；作品的技术/机构条件怎样进入意义？

这六类是此次研究者提出的横向问题，不是六项普遍必经工序。作品也可能从绘画、偶发材料或声音开始，逐渐找到结构，不必先写一份完全确定的剧本。

## 3. 可独立深入、也能交叉使用的研究方向

### 3.1 抽象电影、视觉音乐与运动绘画

**代表和文献：D01，Fischinger《Motion Painting No.1》（1947）。** 作者把不断发展的绘画与电影的色彩、节奏和运动联系起来；作品属模拟时代的电影实践，是数字表现可对话的历史资源，不能倒写成数字艺术的制作事实。

**应研究：** 线条、色块和运动能否自己形成期待、回应和记忆？结构来自音乐的逐拍对应、跨段落关系，还是有意抵抗声音？有限元素如何逐渐改变密度、方向、尺度和图底关系？没有角色是否仍存在可感知的张力？

**影像入口与下一证据：** CVM的Fischinger档案页可进一步定位授权放映/保存资料；本轮未取得可直接验证的完整影片播放。先看完整作品再选一次连续转化，不依据画家声明预先认定观众一定产生音乐般感受。

**边界：** 视觉音乐不是一切“会随音乐动的图形”；音乐可有同步、反同步与独立层次。不能把抽象等同无意义装饰，也不能强迫每次非叙事变化解释成角色剧情。

### 3.2 规则、随机、系列与算法造型

**代表和文献：D02，Molnar的《Interruptions》《(Des)Ordres》及machine imaginaire。** 声明强调用相近系列比较视觉差异，只接纳少数结果；电脑帮助组合，审美价值仍需要作者判断。她的纸面规则实验早于实际使用计算机。

**应研究：** 规则约束什么、放开什么？小变化何时改变重心、秩序或阅读；随机分布是否只是均质噪点？参数序列进入时间后是进程、循环还是跳变？作者的选择、删减与停止条件在哪里？

**后续材料：** DAM页含各作品系列入口和艺术家书目；程序、实际绘图、相近版本和选择记录可共同研究。当前读的是静态作品方法，迁移到电影的时间组织属于研究假设，不能说Molnar这些系列本来就是动画。

**边界：** “程序生成”不等于机器学习，更不等于失去作者。穷尽组合不是项目必须做法，新奇也不能自行证明质量。

### 3.3 信号、反馈、现场控制与图像表演

**代表和文献：D03 Steina的Violin Power表演；D11 Olivia Jack发起的Hydra项目。** 前者将演奏动作映射到影像位置和速度，后者把视觉来源、多个帧缓冲和变换组合成可实时编排的系统。两者可形成历史对话，不能视作同一设备或同一作品。

**应研究：** 图像由现成视频的控制、实时合成还是输出重新进入输入产生？延迟、累积和消散怎样成为时间感？演奏者做的动作是否可被观众感知？画面稳定、失控、复原之间怎样形成表演？现场控制与预录成片的作品身份有什么区别？

**影像/源码入口：** Steina页有movie与technical description；Hydra README链接在线编辑器、教程、示例和视频反馈参考文献。本轮只读所标正文，没有打开全部链接或运行演示，不以能输出图形代替艺术判断。

**边界：** 声音驱动参数、互相调制和反馈是不同机制；不能把有反应的画面全部称作交互叙事。GitHub工具也不是艺术作品的质量认证。

### 3.4 故障、压缩、媒介痕迹与反透明性

**代表和文献：D04 Menkman。** 本次所读宣言把故障、编码/解码与反馈造成的扰动区分，并反思失误被插件常规化后变成可识别风格的过程。这是艺术家的论述，不能当所有故障作品共享的政治立场。

**应研究：** 破裂暴露哪一层媒介规则，影响理解还是仅装饰表面？受众知道此前的“正常”是什么吗？可重复效果怎样保留具体语境？音频/视频故障如何互相影响？保存原始错误还是保存可再次发生的条件？

**后续证据：** 原版宣言后半、本人的具体作品与过程文档应补读；本轮尚未核看任何故障影像，不声称图像已证实这些命题。

**边界：** 画面损坏并非自动批判技术；设计出来的错误也不必自动判为假。偶发系统故障、艺术化使用与现成特效需要分别判断。

### 3.5 拼贴、挪用、档案与影像论述

**代表和文献：D05 Jafa《Love Is The Message, The Message Is Death》。** Met说明材料来自作者拍摄与电影、新闻、运动、音乐、公众录像等取样；声画存在贴合与反节奏。这使“美术”研究扩至图像来源、质地、相邻关系和历史位置，而非只研究片内布景。

**应研究：** 图像并置怎样形成联系而非把差异压平？什么片段被摘离原场景，音乐怎样改变证词位置？分辨率、比例、压缩、字幕和来源身份是保留还是清除？创伤、日常、欢乐和公众形象的切换由谁解释？

**影像入口：** 收藏页确认作品媒介与时长，页面不是完整播放；原引用的Jafa访谈可继续定位。本轮不据馆方说明自行写镜号，也不因资料可检索便复制整部受限作品。

**边界：** 不能把拼贴一概降为“素材混剪”；不同图像并非天然可以互换。这里的非裔美国文化语境不能直接当全球通用情绪模板。

### 3.6 游戏引擎、实时模拟与生成的叙述

**代表和文献：D06 Cheng《Emissaries》三部曲。** MoMA PS1正文说明它们使用游戏引擎，角色与环境相互干预，运行可不断演化。机构展示把观众放在观察模拟生命的情境里。

**应研究：** 固定故事与规则允许的行为怎样冲突？角色是否只被动画外形定义，还是由行动可能性、记忆与关系形成？镜头怎样选择不可预先确定的事件；观众进入/离开的时间怎样影响理解？实时输出录成影片后丢失或改变什么？

**影像入口：** D06嵌入Vimeo和艺术家作品站可作为后续入口；2017 Twitch日程只是历史。下一次要分别记录模拟版本、记录片段与实际运行，不能用预告断言系统可持续产生有意义叙述。

**边界：** 游戏引擎也可以用来渲染完全固定的短片；引擎名称不等于开放叙述。“实时”“无限时长”“互动”彼此不能替代。

### 3.7 扫描、摄影测量、点云与非人感知

**代表和文献：D07《In the Eyes of the Animal》。** 工作室说明扫描、360摄影、CT、摄影测量、实时图像、空间声与触觉结合，围绕不同动物的感知世界组织体验。

**应研究：** 扫描为什么要保留空洞、点状密度、遮挡或不完整表面？数据重建与主观转译在哪里分开？观众的尺度、头部朝向、视域和声音位置怎样改变环境关系？同一森林如何成为不同感知系统中的世界，而非换一层滤镜？

**影像入口：** 项目页给出“Into the Forest”“Creating Virtual Worlds”“Sound in 360”三部制作片入口及原始LIDAR/体积探索图的标注，下一步可核看；本轮未看。实际XR、360版和现场大屏版本需要分开记录。

**边界：** 摄影测量/激光扫描并不天然客观完整；艺术模拟不等于直接进入动物意识。工作室具体生物感知数值未经本轮专业核实，不转为科学结论；软件名称也不从宣传文案自动变成推荐配置。

### 3.8 数据、机器学习、收藏与机构可见性

**代表和文献：D08 Anadol《Unsupervised》2022—23 MoMA展览版本。** 机构说明以收藏公开数据训练模型，并以大厅光、运动、声学和天气输入影响实时图声。

**应研究：** 数据选择了哪些作品和分类，遗漏了谁？数据与最终形态的联系是否可追查，还是只有“海量数据”的宣传？作者、模型、策展制度、显示空间分别作了什么决定？输出的持续变化怎样区别于预先设计的循环？

**影像/论述入口：** D08链接现场文档、艺术家问答与关于艺术史/机器的文章。先核版本、输入与展示，再读支持和反对意见；本报告未审代码、模型或论战全部文献。

**边界：** 训练数据公开可见不自动证明全部训练/再用权利，馆方的“梦/幻觉”是艺术话语，不是机器有意识的证据。作品发行、NFT与本次实时展览的条件不能混为一体；本轮也不据单一机构赞语做质量判决。

### 3.9 多屏、投影、装置与空间化剪辑

**代表和文献：D09 Julien《Ten Thousand Waves》。** 工作室页实际分别列九屏、三屏与名为Better Life的单屏版本，媒介与声音/时长说明使版本差异可追查。

**应研究：** 画面是连续、同时、冲突还是相互遮蔽？观众身体的转向、移动、等待怎样参与剪辑？声源是否引导注意，何处允许漏看？屏幕之间的空白、投影尺度与建筑条件是否构成作品？单屏转写怎样重新组织注意？

**影像/空间入口：** 工作室页有Film和各展示版本图档。下一步需分看完整单屏材料、同步多屏记录、平面图与现场行走文档；一个宣传录像不能证明装置观看经验。

**边界：** 多屏不是把单屏并排复制；沉浸也不是屏幕越大越好。作品在中国取景并联系历史/迁移，不等于作者身份或观看立场可以免于讨论；后续需要独立评论与相关中文研究。

### 3.10 数字化身、身体、流行视觉与认同

**代表和文献：D10 陆扬《妄想罪与罚》。** M+说明身体近景与数字化身世界并置，并有电子音乐合作。此处的3D不是只为角色设计更精致的模型，而可研究身体、复制、性别、痛苦和宗教/流行符号怎样被重新组织。

**应研究：** 化身像作者到什么程度，何时复制、变形或重置？动作和音乐怎样塑造身体；真实身体痕迹与数字不受损之间怎样发生张力？文化图像是世界规则、角色立场，还是仅作图标引用？

**影像入口：** M+收藏/影像馆信息可继续查询实际观看；本轮仅短正文，不用馆方描述替代14分37秒实看，也不把一位艺术家代表全部中国数字艺术。

**边界：** “日式”“赛博”“怪诞”等泛词不足以解释具体作品；数字身体不自动意味着解放或去人性化。需要创作者自己的说法与评论互证。

### 3.11 手工、擦除、数字拍摄/剪辑与混合材料

**代表和文献：D12 Kentridge《City Deep》。** 2020访谈说明作品从绘画中发生，擦除/重画与制作时间本身参与思考；该片改用数字相机、电脑剪辑。这里只能就他谈到的该片和方法说明数字环节，不能倒推此前所有影片均同一设备。

**应研究：** 留痕如何成为记忆、变化与过程，而非后贴“手绘纹理”？画面在制作中发现的意外怎样改变结构？什么时候剪掉仍可保留的绘画，什么时候停留形成重量？数字清理若去掉擦痕，会保留什么、失去什么？

**影像入口：** 原访谈含该片及相关录像链接，可继续核看；本轮未看。作者关于材料手感的选择属于其具体实践，不可升格为手工比数位板普遍更好。

**边界：** 混合媒介不应只是按软件数量计数；绘画、纸偶、定格、实物、扫描和合成可以有不同分工。还应另补中国剪纸/水墨、木偶/定格、刮片/胶片直绘和数字整合的实际作品与工艺档案，本批不冒称已覆盖。

## 4. 风格研究如何避免成为名词墙

“水彩、低多边形、写实、拼贴、表现主义、赛博朋克”混在同一层，容易把材料、造型、历史流派、文化类型和工具混为一谈。后续总纲可让这些词出现，但应分别追查：

1. **历史与文化谱系：** 在何种地区、制度、艺术实践中形成；作者如何接受、改写或拒绝。
2. **具体形式关系：** 线面、空间、光色、图底、材料、密度与比例怎样组织，而非仅视觉相似。
3. **时间及声音：** 这种形式如何运动、停留、改变和发声；静帧样式不能独立代表影视风格。
4. **制作与观看条件：** 它靠哪些工序和协作成立，在手机、影院、展厅或实时系统里如何变化。
5. **作品内部差异：** 何时遵守、何时破坏；不要以全片每张图相似作为唯一一致性。
6. **争议和失败：** 创作者自述、批评者解释、实际材料与研究者假设分别记录，不能只收宣传。

这也是本报告的自我限制：目前对技术机制与展示形式的入口较多，完整风格史、原始图像/连续作品与相互争论的评论仍不足。广域总纲必须允许以后增加独立方向，例如绘画性空间、平面图形/文字、建筑/雕塑/舞蹈与影像关系、摄影真实与非写实渲染等，不把本报告列出的方向再变成新上限。

## 5. 从总地图进入研究时，先补什么证据

本批不替用户选一个统一风格。下一步可以按具体问题选一个成对/成组比较，不把以下全部列为开工前置：

- **声画怎样互相推动：** Fischinger与Steina可作历史/机制对照；先实际看听，再辨逐拍、跨段关系和现场控制，不能只读艺术家感受。
- **规则怎样保留作者决定：** Molnar与Hydra可研究限制、变体和选择；要区分静态系列与连续实时影像，代码试验仅回答机制，不自动产出作品。
- **身体与世界如何被数字化：** 陆扬、Cheng与MLF可比较化身、行动规则与感知视点；它们不同媒介/时长不能用单个截图打分。
- **图像从哪里来，怎样被重新观看：** Jafa与Julien可比较档案拼贴和空间化观看；须加入文化语境、实际段落与独立评论，不将受压迫经验抽成通用情绪素材。
- **手工痕迹与数字加工怎样相处：** Kentridge及中国/其他地区混合材料实践可比较，先把原工艺与具体数字环节查实，不以滤镜名替代过程。

研究记录无需继续堆同型模板；真正应保留的是：当前问题、读/看的具体版本范围、重要选择与证据、不能排除的另一解释、下一项能改变判断的观察。总纲有开放边界，单次研究有明确边界。当前12份入口完成不等于12个领域或12部作品学习完成。

## 6. 历史美学与绘画风格的下一层路线（当前待系统研读）

数字艺术线不能替代传统形式与艺术史。后续还须分别研究：写实/自然主义与日常观察；表现主义的造型/明暗/空间；超现实、象征与诗性图像；印象性光色及绘画痕迹；构成、几何与图形组织；极简、留白、稀疏运动与持续时间；装饰、民间、工艺与仪式；漫画/插画/版画与银幕语言；粗粝、低保真与材料痕迹；摄影性写实与合成世界。每条都须查历史、具体作品和相反办法，不以这些候选词宣布已完成风格史。

水墨/水彩等材料、表现主义等历史美学、低多边形等形态策略、赛博朋克等文化类型、Blender等工具、VR等观看形式分栏记录；可交叉使用，却不属于一套同层风格标签。地域也不是风格：同地创作者有不同立场和形式，跨国制作可能共同改变画面。

数据艺术还须独立追查数据怎样采集、测量、筛选、分类、映射成图像/声音，如何表现遗漏与不确定。它可完全不使用机器学习；规则生成也未必来自外部数据。浏览器/网络原生艺术、远程现场、延迟、分布式输入与连接条件同样进入观看/时间研究，不只登记一项Web工具。

## 7. 风格研究问题表：传统、影视与数字方法交叉推进

下表是待逐题完善的研究线路，既有材料只支撑所标局部，不能据此说已经研究完某一流派。作品可进入多行，名称也可能在不同语境有不同含义；历史流派须另读原始论述和专门研究，不用相似外观反推影响关系。

| 线路 | 重点查什么，而不止找外观 | 已有材料及仍需取得的证据 |
| --- | --- | --- |
| 写实、日常、自然主义及其偏离 | 生活细节怎样被选择，表演/场所/时间何处被组织；摄影写实和CG物理写实不是一回事 | 刘健与蔡明亮评论、前批Minari资料；需实际原片与生产材料，历史谱系未系统读 |
| 表现性、变形与心理空间 | 明暗、几何、身体、布景、镜头怎样形成紧张或疏离，何时反而显得陈套 | Persepolis关于不同参考的作者说明、Deren资料；需历史表现主义原作/研究和相反解释 |
| 象征、诗性、仪式与超现实 | 物、身体、联想和文化知识怎样展开，图像的开放性与持续观看如何相处 | 石榴的颜色异议对读、郑多喜、Bodyless；未实际验证段落，不能汇成万能符号字典 |
| 装饰、民间艺术与工艺 | 图案、物质、仪式、身体动作和文化处境怎样互相作用，不把装饰降为无功能 | 旧中国水墨/剪纸资料、Norstein访谈；需更多原设计、工艺与非英语研究 |
| 漫画、插画、版画与平面叙述 | 格子、排线、图形简化、静态页面怎样转成时间，漫画改编怎样重新组织信息 | Fantastic Planet制作史与Persepolis直接说明；具体纸面/银幕对照未做 |
| 绘画性与印象性光色 | 笔触、色块、边缘、明暗和画面深度在运动中怎样变化；不是一层绘画滤镜 | Fischinger、Kentridge、Malt方法、Gold索引；需NPR连续镜头和原画/渲染分解 |
| 极简、稀疏、留白与持续 | 少元素怎样形成期待、节奏与差异，何时是有意省略、何时信息不足 | Molnar规则声明、刘健/蔡明亮评论、Deren研究；需作品时长与声画证据 |
| 几何、构成、视觉音乐 | 线面色形、图底、比例和节奏能否建立无需人物的结构 | Fischinger与Molnar原文；从静态系列迁移到电影须实际核验 |
| 照片、档案、拼贴与混合质地 | 来源、画幅、分辨率、印刷/扫描痕迹、并置与声音如何改写图像 | Jafa馆方材料与Julien版本说明；需完整作品、引用史和独立评论 |
| 手工痕迹、粗粝与低保真 | 擦痕、抖动、接缝、噪点、压缩怎样成为形式，哪些只是制作故障 | Kentridge、Menkman与手工材料文献；二者不同历史/立场，不能统称一种风格 |
| 非写实三维、2D/3D混合 | 轮廓、光影、纹理与镜头怎样受控；风格化不是统一降低模型精度 | Malt与材质/色彩文档、Flow作者问答；缺工程与成片复现 |
| 幻想、科幻与文化类型 | 世界规则、技术想象、阶层/生态和视觉母题怎样共同形成，不以题材名称代替形式 | Fantastic Planet、Bodyless与数字身体资料；赛博朋克等类型的历史谱系与反例仍需专读 |
| 算法、数据、实时与生成 | 规则、选择、输入与输出如何追溯，怎样区别循环、表演、模拟和模型生成 | Molnar、Hydra、Cheng、Anadol及创意编程仓库；未执行或经历实际输出 |
| 空间化、沉浸与扩展观看 | 多屏布局、尺度、移动/头部方向、连接、触觉、声音与观众的选择 | Julien、MLF、Bodyless档案；需版本、平面图、同步记录和实际体验，不能用宣传片替代 |

这些路线没有穷尽美术风格。后续艺术史、作品和评论中出现新关系，优先修订问题与证据路线，不为了保住分类把作品硬塞进去。
