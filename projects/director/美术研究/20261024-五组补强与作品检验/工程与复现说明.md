# 工程和复现范围

本机实际执行Blender 5.2.3 LTS e13b728c6880，现有Steam安装；没有新装软件/插件。所有输出只写本任务目录。重渲染会覆盖对应版本生成文件，研究原版已存媒体包；再次实验先复制目录或使用新版本名，不覆盖主证据。

在解压本批原创媒体包后的根目录，可用同版Blender的后台模式运行：

```text
blender --background --factory-startup --python make_folds.py -- --version v3 --mode stills
blender --background --factory-startup --python make_folds.py -- --version v3 --mode movie
blender --background --factory-startup --python make_folds.py -- --version v3 --mode gallery
blender --background --factory-startup --python verify_gallery.py
blender --background --factory-startup --python render_single_factors.py
blender --background --factory-startup --python verify_native_and_video.py
```

`render_controls.py`另外读取V2 `folds-base.blend`；先运行`--version v2 --mode stills`或使用包内已有V2工程。V1快照文件是制作时源码存证，不直接从其子目录启动；主源码仍保留v1/v2/v3分支。`build_verification_boards.py`需Python的Pillow/numpy和Windows Arial，负责联系表/数值检查，不生成3D作品。

原生V3动画工程可直接打开并在时间轴播放/编辑，形变键与材质/灯参数已保存，不需要脚本handler。V3展示工程的屏幕纹理已实际pack并重开验证；V2展示工程是保留的中间版本，贴图可从同目录base-0192.png重连，不宣称旧工程也已打包。V3的47对象中包含一个不渲染的旧领片，保留作版本构造痕迹，不计可见新领口效果。

视频静音、16秒/24fps/384帧/768×576；静帧960×720。所有媒体是本轮自写程序生成，不使用第三方贴图、参考艺术家专属符号、原音乐或他人角色资产。程序形变不是物理布模拟/人体动作捕捉，细条不是groom。

gallery的`angle_y`是RNA传感器角，输出纵视场另由投影矩阵计算；生成后的`verify_gallery.py`会重开工程并补正确记录。0.9米广角说明图单独标镜头改变，不能混入固定视场距离对照。

重开、有限坐标、帧数、编码/像素检查只证明所记录的技术项；不能证明艺术表达、真实听感、展场或观众效果。另存的reopened-local-edit.blend是扣件横移6厘米的核验副本，不是V3正式输出源。
