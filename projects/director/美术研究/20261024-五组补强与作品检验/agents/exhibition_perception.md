# R12补强：展示尺度、观看位置与知觉——展览证据和待执行检验

研究日期：2026-10-24。执行范围：馆方／艺术家原始记录、安装照片核看、展示方法与视角计算。只写本报告及 `reference_images/exhibition/`，未改主稿、旧档或 Git。

本批实际读到 **11个作品／展览案例、15份实质正文来源**（其中专业方法3份），并通过 `view_image` 实际查看 **7张来源照片**。其中3张有现场观众与空间尺度参照，2张为徐冰同件作品正反面，2张为UCCA入口／多屏室。未观看作品完整连续影像、未到现场、未做观众实验。2个局部下载文件不完整，另2张请求未收到内容；均不算图片研读成果。

本报告的主要判断是：**展示条件会参与作品的表达结构。数字画面应同时交代画面内尺度、实际显示尺度、观看位置与连续时间；仅写分辨率和画幅不能完成这项工作。**下面把机构事实、实际看图、研究推论和待做验证分开记录，不把机构的体验性宣传语言当作自身体验。

## 1. 先区分四种尺度及两种时间

| 项目 | 应记录什么 | 容易发生的混淆 |
|---|---|---|
| 画面内尺度 | 人、物、建筑的相对大小；透视、镜头位置、遮挡；需要辨认的最小叙事细节 | 画面里的巨大人物，不等于观众面对巨大实体；超近特写也可能只在手机上占几厘米 |
| 显示的物理尺度 | 实际亮起的图像宽高，含信箱黑边／裁切；屏幕或投影面形状、离地高度 | 显示器对角线不是有效图像宽度；展厅体积不是画面尺寸；藏品包装尺寸不是安装房间尺寸 |
| 观看尺度 | 眼到屏幕距离、偏轴角度、坐／站／轮椅视高、是否需要抬头或转身 | 相同像素或相同视角不能保证相同身体、亮度、社会与声音关系 |
| 行动尺度 | 能否接近、绕到后面、穿过光束、选择通道、操作接口；他人是否挡住 | 沿作品走动与在视频里看摄像机绕拍，给予观众的决定权不同 |
| 作品时间 | 单路片长、循环起点、多个通道的同步／异步、动作和声音节奏 | 多屏不是把一段电影同时分成若干缩略图即可 |
| 观看时间 | 从哪里加入、实际停留多久、排队／限时、为看另一屏而错过什么 | 展览总开放时长、作品片长与一次可观看时长互不等同 |

这是本报告的分析分类，不声称为某位艺术家所用的理论体系。

## 2. 案例：原始参数和本轮证据边界

### 2.1 有人体与空间关系的三组安装照片

**Pipilotti Rist《Pour Your Body Out (7354 Cubic Meters)》，MoMA，2008–2009。**机构记录为多通道彩色有声投影，配圆形坐具和地毯；新闻稿给出约25英尺高、横跨约200英尺的投影范围，7354立方米指中庭体积。声音来自坐具，窗帘参与改变中庭照明。这些数值不能拼成一张精确矩形屏幕图。[MoMA展览正文与媒介说明](https://www.moma.org/calendar/exhibitions/307)、[2008-11-18新闻稿，第1页及第2页开头选读](https://assets.moma.org/documents/moma_press-release_387162.pdf)

实际看图：`moma_rist.jpg` 中墙上植物／果实／身体细节远大于观众；观众在浅蓝圆形软座上坐、躺，另有人站立、走动，建筑竖向构件分割右侧图像。图支持“多种姿态与观看方向并存”，不支持“每人沉浸／情绪被治愈”，也不能由照片判断音量、色准或精确观看距离。摄影：Thomas Griesel。

**Olafur Eliasson《The weather project》，Tate Modern，2003–2004。**艺术家档案说明半圆屏幕、天花镜面、人工雾与约200盏单色频率灯共同组成装置；在不同位置可以看到构造与镜面背部。所读原始正文没有提供大厅精确长宽高，故未采用网上二手尺寸。[艺术家展览档案，正文与安装图注](https://olafureliasson.net/exhibition/the-weather-project-2003/)

实际看图：`weather_project.jpg` 中远端巨大黄圆、重复建筑跨间与许多很小的观众形成尺度对照；有人站、坐、躺。它证明照片选取的视点能显示这种相对关系，不能量出现场人的视角，更不能把橙色照片当作现场绝对亮度测量。摄影：Tate Photography，Andrew Dunkley、Marcus Leith。

**Jeffrey Shaw／Dirk Groeneveld《The Legible City》，1988–1991相关版本，ZKM馆藏记录。**机构列明自行车接口、计算机与定制软件／电子装置、小地图显示器、投影机和凹面投影，安装尺寸可变；骑行动作控制虚拟城市中的行进。不同硬件版本不可一概当成原初配置。[ZKM作品记录，Theresa Rößler撰文及技术条目](https://zkm.de/en/artworks/the-legible-city)

实际看图：`zkm_legible.jpg` 显示骑车者、面前大幅文字城市投影、较低的小地图屏、地面设备与线缆。身体—操控—主图像—定位信息的位置关系可辨认。未操作，故未检验延迟、阻力、导航难度、真实视野覆盖或无障碍使用。图注：作品© Jeffrey Shaw，摄影© ZKM／ONUK。

## 3. 四组深入对照：哪些关系可以迁移，在哪里失效

以下为研究者综合推论，不是原作者自述或已证明的观众反应。

**A. Rist／Eliasson：画面包围与身体停留。**我们能迁移的是先决定观众的姿态、视野边界和停留方式，再安排内容的细节密度与注意转移。多方向场景不应把每处都设为必须同时读取的主信息。实际照片里“坐、躺、走”并存，但它也有其他解释：开馆时段、人流、摄影者选片、场馆社交习惯。不能从一张照片归因于某个色彩或尺寸。转为桌面视频时可以保留色彩与节奏的一部分；真实大厅的上方反射、共同停留、离开与返回权无法靠加一层广角镜头完整保留。

**B. Shaw／Campus：观看位置是叙事分配。**可迁移的是画一张简图，标出谁控制、谁观看、哪条信息只有何时何地才可见，而不先承诺“更互动”。如果原创数字作品采用自动播放，得说清楚放弃了哪些主动决定；用镜头剪辑安排同样信息可以成为另一版本，但不是原来的行动结构。失效条件包括输入到反馈延迟、接口被遮挡、不能接近、只有屏幕录像、声音误导定位。我们尚无各作品这类失效的实测记录，不能写作其历史缺陷。

**C. 杨福东／曹斐：多屏多媒介的展示，与把故事拆得支离破碎的差别。**应先写“错过某路是否仍成立”“是否允许不同入口”“路线选择带来哪种信息差”，再决定屏数。对直线情节短片，如果身份反转或关键行动只能在某屏短暂出现，观众没有看到可能是表达失败；如果作品本就允许片段式组合，则缺看一屏未必是失败。本轮没有完整多通道素材，不能代艺术家判定哪种遗漏是有意安排。单屏转译至少要另写时间顺序与取舍表，不能把全部画面拼进一个小格阵列就称表达保留。

**D. 徐冰／McCall／Flavin：材料、光路、身体的可达性。**可迁移的是识别作品中必须由真实空间承担的关系：正反揭示、穿越、被挡、换一个位置才出现的构造。在原创作品中，如果这些只是画内角色的行动，单屏动画可以表现；如果目标是让观看者本人绕行或被遮挡，单屏动画只是对关系的描绘。物理版本的判断须留到实际空间原型，不用“沉浸”一词抹平区别。正反照片也不证明徐冰现场允许所有人自由绕行，仍要安装平面和管理资料。

**共同的制作约束。**Turrell安装稿提示：设计图定了，不代表显示效果已经建立。数字小件也要留真实输出测试时间，至少区分成片文件、播放设备、有效显示区、声音路由和场所。可以将多屏低成本样机放在同一桌面验证同步内容与可读性，但不能据此验收展厅体感。投影机灯量、黑位、融合边缘、反射眩光、声泄漏与维护工时本轮均未实测，不能用网络参数虚构通过。

## 4. 专业展示方法：实际选读与推论边界

**Smithsonian《Guidelines for Accessible Exhibition Design》。**本轮文本选读PDF物理第2–7、13–15、27–28页，以及视听与流线章节的局部段落；没有通读111页。材料要求从较矮／坐姿观看者、玻璃柜与文字实际观看距离、背景杂乱和多人遮挡等情况思考展陈，而非只代入站在正中的平均成人。[机构指南PDF](https://www.sifacilities.si.edu/sites/default/files/Files/Accessibility/accessible-exhibition-design1.pdf)

由此转成我们自己的工作方法：先定需要被读到的内容，再用两种视高和边缘位置检查；记录反例，给坐姿、等待和绕行留位置。这里没有拿旧馆方指南替代当前中国的场馆、消防或建筑规范，也没有把其中照明／字高建议当作所有艺术作品的审美阈值。

**PsychoPy官方单位说明与视角函数。**实际阅读 `Units for the window and stimuli` 正文，以及 `viewtools.visualAngle` 的说明与例子。它们提供将物理尺寸、距离和像素分开记录的技术方法；这里没有使用其软件开展知觉实验。[单位文档](https://psychopy.org/general/units.html)、[视角计算说明](https://psychopy.org/api/tools/viewtools.html#psychopy.tools.viewtools.visualAngle)

本轮没有读到并验证“某个固定视角必然产生某情绪／注意力”的原始实验，不作这类结论。形状和亮度相同也不能保证不同人群有相同辨识表现；需要对具体作品和具体人实际观察。

## 5. 已实际完成的视角计算：只验证几何，不代替观看

使用公式 `θ = 2 × atan(W / (2D))`，转成度；假设观看者在平面图像中央的法线方向，`W` 是实际显示宽度，`D` 是眼到该平面的距离。偏轴、曲面、视力、画面亮度、声音、身体运动不在此公式内。

| 假设条件（尚未量取实际设备） | W / D（米） | 水平视角 |
|---|---:|---:|
| 桌面图像近距 | 0.30 / 0.60 | 28.072487° |
| 同一显示宽度，距离加倍 | 0.30 / 1.20 | 14.250033° |
| 竖持手机中的图像宽度 | 0.065 / 0.35 | 10.610219° |
| 2米宽投影，距离4米 | 2.00 / 4.00 | 28.072487° |
| 2米宽投影，距离2米 | 2.00 / 2.00 | 53.130102° |
| 5毫米显示细节，近距／较远 | 0.005 / 0.60；0.005 / 1.20 | 0.477462°；0.238732° |

这些是实际运行代码产生的数字，**条件是人为设定，设备没有实测**。桌面近距与2米投影／4米距离可以同为28.07°，但物理位置、他人遮挡、声音、亮度和接近权仍不同。细节的几何角度变化也不等于已知的人眼辨认阈值。

代码还与官方例子“0.2米物体、1米距离=11.42118627°”校对，误差小于 `1e-7` 度；另一断言校对两组等比例条件视角相同。输出另有25英尺=7.62米、200英尺=60.96米、12英尺=3.6576米的精确单位换算；没有借换算填补实际观看距离。

## 6. 给本轮原创数字作品的小型检验方案（尚未执行）

不预填尚未出现的作品结论，也不要求先建展厅。根agent可先落实下面的最小批次，区分几何校对、作者自查和外部观看。

1. **冻结一版可播放输出。**写版本号、画幅、总时长／循环、声音模式、3项必须读出的叙事信息与允许保持含混的信息。若只有静帧，只检验静态关系，不验收节奏、动作或因果连续。
2. **固定两个可复现的观看条件。**同一设备、同一亮度设置与房间位置，量取实际亮起的图像宽高、眼距、视高、缩放与裁切。近距和较远位置任选可做到的组合，先测量再代入代码，不能把上表假设写成实际布置。没有设备测量能力时，把实测状态留空，先输出待测表。
3. **无提示观察，再问具体内容。**观看前不解释主题；结束后记录“谁对谁做了什么”“什么物件发生了变化”“注意先落在哪／哪里没看懂”，原话与作者期望分列。人数和招募情况如实写；只有另一个agent读图时标为模型审查，不称观众反馈。错读不自动等于坏，应对照冻结的必读信息。
4. **尺度与遮挡分开改。**只换距离复看；随后只换坐姿／左右边缘位置，检查关键人物关系、道具轮廓与文字是否仍可分。一次只改一项，保留导致丢失的帧和位置。若用叠黑块／缩略图模拟遮挡，它只检验画面缺失容错，不是现场人体遮挡测试。
5. **连续时间必须播放。**有循环时分别从开头和任意中点进入，至少经历一轮，记录关键原因是否只能在开头获得；有多路时记录通道是否同起、转头是否错过必须信息。静态联系表不能替代这些动作。仅有单屏作品就不扩建多屏测试。
6. **声音单列一轮。**对比原声与静音，记录哪些信息因静音而损失；若宣称方向性定位，再在真实扬声器／耳机条件测，不用立体声文件名证明空间声成立。字幕或图像补偿方式由表达目标决定。
7. **做一个有因果关系的修订。**只针对一项实际错读或丢失，改尺寸／对比／持续时间／视线引导中的一项，保存前后版本并在同条件重看。不能仅换更漂亮的画面就写“知觉已优化”。

建议最小记录表字段：`作品版本｜条件ID｜实际图像宽高｜眼距/视高/偏轴｜环境/亮度设置｜缩放/裁切｜声音｜观看者类型与人数｜进入时间｜原话/观察｜必读信息结果｜缺失证据｜改动｜复测结果`。

**判据由作品目标决定，不伪造通用分数线。**如果必须辨认的共同物在较远条件被当成另一件物品，这是可复查的失败候选；如果目标只是感到两人关系发生转变，不应要求每位观看者准确说出道具材质。如果关键关系在手机版失败，可以另做构图与时长，而不是声称手机展示等同大型安装。
