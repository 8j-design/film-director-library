# Codex 使用演示：导演构思与拉片 Skill

这是一份约3分钟的现场演示脚本。展示的是怎样在 Codex 中调用技能、给出任务和判断结果；下面的输出示例是本次在当前聊天中读取 Skill 后，根据自编场景实际生成的文字结果。没有声称已经在新聊天里测试技能菜单、视频播放或拍摄效果。

## 演示前准备

1. 在 Codex 中新建一个聊天。技能包安装在用户 `.codex/skills/` 下；本机已经放好。若新技能未出现，可以重新打开 Codex 或新建聊天再检查。
2. 打开聊天输入框。可以输入 `$director-conception-and-shot-analysis` 明确指明技能；不同客户端的技能选择界面可能不同，以实际界面为准。
3. 将下面的提示词与场景一并粘贴，发送即可。这是普通聊天输入，不是终端命令；不需要写代码。

## 第一步：输入任务

```text
请使用 $director-conception-and-shot-analysis，帮我为下面的场景做导演构思。

我想让观众感受到两个人之间有亲近，也有一点隔阂。条件是一间普通厨房、两位演员，尽量少调度。

夜里，母亲在厨房给女儿装一盒饭。女儿站在门边，说自己赶时间。母亲把盒盖扣好，推过去。女儿伸手接住，却没有马上离开。母亲继续擦桌子。过了一会儿，女儿说：“我明天把盒子带回来。”母亲点点头。

请先说场景中能确定的事实，再说你的导演构思、画面和声音选择，最后给我一个可以比较的简单实验。请标出哪些还没有验证。
```

分享时可以说：“我给 Codex 三样东西：一个场景、想表达的感觉，以及实际制作条件。”

## 第二步：看结果怎样帮助决策

本次按技能方法处理这段文本，得到的精简结果如下：

- **确定的事实**：母亲装饭、推盒；女儿接住后没有立即离开，说会把饭盒带回来；母亲点头。她们此前发生了什么，文本没有交代。
- **表达方向**：让关心先通过装饭、接盒和女儿短暂停留呈现，不急着解释关系。还盒子可以成为明天再见的一条线索；这是解释，不是人物内心的既定事实。
- **空间与表演**：母亲在桌边，女儿靠门，饭盒连接两人的行动。演员如何停留、母亲擦桌时是否看女儿，留到排练中比较。
- **摄影选择**：先试一个能同时看见桌、门和两人的机位，让递盒与反应处于同一空间。若手部动作或人物反应看不清，再考虑靠近或切换镜头；需要结合真实场地检验。
- **声音选择**：先试盒盖扣合、擦桌和厨房环境声，再决定是否需要音乐。这里是构思，没有实际录音或听感结论。
- **小实验**：机位、走位和临时声轨保持一致，只比较接盒后马上说话与停顿片刻再说话。连续看听后，判断停顿是否有助于人物关系，还是只是拖慢节奏。拍摄、试听和观众反馈都还没有做。

分享时指出：结果不只是一串“中景、特写、暖光”，而是把人物、空间、画面和声音放在同一场景问题中讨论，并留下可修改的选择。

## 第三步：继续对话，修改一个选择

在同一聊天里继续输入：

```text
如果厨房太小，无法同时拍到门和桌子，请保留人物关系和低成本条件，给我两个替代方案，并说明每种方案会失去什么。
```

本次按 Skill 产生的示范回应：

- **方案 A：桌侧双人近距离画面**。从桌侧拍到母亲和女儿上半身，门不完整出现。优点是保留两人的同框与递盒；代价是“女儿靠近出口”的空间信息减弱，可用她开场站位或画外门声补充，但声音仍须现场测试。
- **方案 B：母亲桌边镜头与女儿门边镜头交替**。分别保证人物和动作可见，在交接处核对饭盒方向和视线。优点是适应狭窄空间；代价是共同空间感变弱、剪辑可能改变原有等待的节奏，需要把两个镜头实际连起来看。

这一步展示 Codex 的作用：提出有取舍的方案，供创作者判断；方案还需要现场和连续影像验证。

## 如果要展示拉片

换成以下提示词，并提供实际可读取的片段或文件：

```text
请使用 $director-conception-and-shot-analysis，分析我提供的这个片段。我想研究人物之间的距离怎样变化。请区分实际看到、听到的事实，你的解释，以及没有核实的内容；最后提出一个能用于原创场景的小实验。
```

如果当前 Codex 环境不能实际读取视频或音频，就现场说明工具限制，改用可读取的材料做有限分析。不要把文字摘要、截图或其他人的评论说成自己完整看听了原片。本次分享包未提供真实片段，也未测试影片播放。

## 结束时怎样总结

“这个 Skill 帮我把剧本中的人物关系，转化成空间、表演、摄影和声音的选择；分析影片时，它要求把事实和解释分开。我们还可以继续提问题，让 Codex 根据实际条件给出不同方案。最终哪个方案成立，仍要靠排练、拍摄和观看来检验。”
