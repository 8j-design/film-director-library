# 《海的背面》单幅画面分析与限定
日期：2026-11-05。状态：画面分析与第一版设计建议；未生成图片，未制作提示词。

## 用户已确定的范围
只做一张图的前期分析。人物为舞台布景维护者，开演前正在修补海景布。希望画面给人梦幻海边的感觉，仿佛这个人真的身处海边；但画面中的实际物理空间仍为舞台。
六图短篇不再是本轮交付。不开启生图或提示词制作。

## 核心分析
单幅画面需要同时承载感受和辨认。建议的观看主次是：整体光色和大面积海景让人先感到海边；随后从手、布的连续关系、裂口与一处舞台边界认出实际工作。这是设计意图，不是已获观众验证的效果。无需强求每位观众严格按同一秒数观看。

困难有三：舞台标志过强会把海景压成普通背景；海洋幻象过强会把人物放进真实海滩而抹掉工作；气氛与人物过糊会使修补不可读。限定应直接处理这些矛盾。

## 建议主方案：从海景布正面略偏侧看工作
一张横幅完整场景，先以3:2作为可调整的构图起点；非拼贴、双画面或前后对照。
巨幅手绘海景布悬挂在后方，占据大部分背景，海平线和远海形成横向展开。画面右下三分区附近，一位成年维护者坐在低凳上，身体略侧向画面内，俯身看自己的手。
布的右下缘被拉近到他面前的低工作台上，沿途保持同一块布的连续性；裂口位于可接近的下部，由桌面支撑。观众能从工作区沿布回看到背景里的海。人物没有站在真实海水中。
前景保留少量舞台地板，画面一侧选择露出一小段布边/悬挂或侧台边界，足以提示制作空间。实际剧场尺度与修补工艺尚未调研，不将此虚构布局称为行业标准。

## 要素与作用
| 要素 | 建议第一版限定 | 作用与代价 |
|---|---|---|
| 人物 | 一个成年人，朴素旧工作服，松弛而专注；低头处理布料 | 维护者以任务进入画面。精致礼服、夸张悲苦、仰头凝望海会改变叙事重心 |
| 海景 | 平静远海、较低的波纹对比、舒展海平线；暂选黄昏将入夜的柔和天光 | 形成安静、略梦幻的海边感。惊涛与密集奇观会争夺修补动作 |
| 工作区 | 一处裂口/补片，两手围绕同一处工作；一手稳布、一手牵线的设计待工艺依据复核 | 不把辨认全部押在细针是否可见；补片、针脚和布的状态可共同传递修补 |
| 材质 | 海景大部分连贯，近处弯折和掀起边缘显出画在织物上的质地 | 同一物体既提供海的感受，也说明海如何被制作。四处大褶皱会把海平线变成窗帘 |
| 空间尺度 | 人、凳、桌和手够到的布保持常识比例；背景布明显大于人 | 从既有渡口V6反例吸取教训：不能只缩小人物而保留巨大的工作器具 |
| 观看距离 | 能见人物上身、手、支撑与足够海景的中远景；人不要缩到只剩剪影 | 保住海边环境感与动作的同读。精确人物占比留给草稿验证 |
| 光 | 作为开演前的舞台试光假设，以柔和大面积侧前光模拟海边散射光，人物与背景方向一致；修补区保留清晰亮度 | 人和海处于同一光环境，不像贴在背景前。显眼聚光束会先强调演出现场 |
| 色 | 先试低饱和青蓝、灰绿及少量珍珠色暖亮部，衣服降低花纹与色块冲突 | 梦幻来自空气层次与颜色呼应，具体时段/色温不是固定情绪公式 |
| 地面 | 少量真实舞台地板可辨，适度承接蓝色光；无须实水、沙滩或镜面倒影 | 维持舞台实体，同时让海景颜色进入人物所在空间 |
| 舞台证据 | 选一处边缘或结构，再加布与修补关系即可 | 过多观众席、红帘、灯架和设备会压倒海边感 |
| 道具 | 低凳、低台、有限针线/补布等必要物件；本轮不加入吃饭情节 | 所有显眼物件应与当前修补有关；不把旧六图内容塞入单幅 |

## 必须守住的关系
1. 只有一个真实空间：舞台。海景的画面、光和身体关系造成海边感，不引入真实室外海滩或魔法传送。
2. 手中被修补的布必须能连续接回巨幅海景布，不能变为修衣服或独立围巾。
3. 裂口有可达高度，布由桌面或身体实际支撑，手的任务可分辨。工具、布边与手不互相穿透。
4. 海景是主要氛围，人物工作是主要事件；舞台设备和装饰次之。
5. 雾与虚焦只能柔化次要层次，不能覆盖工作动作与关键布边。不以大海漂亮就判整幅成立。
6. “开演前”首先是构思的时间条件，单张图未必能独立证明。可用仍空置的舞台和试光状态暗示；不靠大字时钟或告示强行解释。

## 可调整项
人物性别/年龄细分、左右位置、精确比例与画幅、清晨或黄昏、偏写实或稍绘画化，可在保留上述关系下调整。第一版选择安静黄昏、朴素人物和手绘织物是设计建议，不是用户已经逐项确认的决定。背景画法和衣着先服务主体，暂不锁定某位艺术家或某一模型。

## 根据既有研究提出的判据
- 《复验结果与研究总结》强调物件、行动条件、观看位置共同成立，技术运行和术语不替代表达。
- 《A07-渡口短笺四版原创与回原作检验》里的近手失焦提醒：接近镜头或气氛漂亮不保证抓持与关系可读。
- 《A07-渡口远景三轮与经典留白反检》里的V6与V7提醒：画幅中的大小与世界尺度分别检查，减少亮点和视觉事件比只拉远更重要。
上述是已有局部试作给本设计的提醒，并非新画面的成功证据。

## 以后看草图时的问题（此次不执行生成）
先不展示创作说明，观察能否同时读到海边感、一个人在修补、这片海是布景；工作区是否连接同一块海景布，环境/人体/桌凳是否同尺，舞台标志是否抢先压倒海边感。感觉成立而工作不清，优先修动作/遮挡/距离；工作成立而海边感弱，优先修海景连续性与光色，而不是加无关装饰。两者均成立后再讨论面部、针线细节和最终画风。
