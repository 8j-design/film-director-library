## 二、视频：它把“漂亮的角色”组织成了可接近的海边经验

### 1. 造型既有动画提炼，又保留身体与材质的立体关系
人物面部有经过简化的鼻、颏、眼形和光滑面部，比例较图1自然；发型同时有成束的总体走向和分散的细发。人仍有明确的肩颈、肘膝、衣褶和身体重心线索。它接近“偏写实的风格化CG视觉”，不等于写实摄影，也不能据风格判断实现方式。

片中多种发型、眼镜、服装和发辫／马尾交替。气质相近不等于同一人物全片身份稳定；也不能单凭造型差别就判模型失控，可能是多人物片段的编排。

### 2. 光通过不同表面发生变化
开头深发边缘有细亮点，肤面亮部较宽且柔，眼镜有反射，水面则有更强、更碎的亮点；后段薄衣料在背光处变亮，草帽与发丝又形成不同疏密的遮挡。光的作用不是给所有东西同样涂白。

冷一些的蓝色海水与偏暖的肤面/发缘并存；清亮段与低太阳位置的暖光段也不同。因此不能简单概括“全片统一低饱和蓝绿滤镜”或“柔和等于没有强亮点”。

可见大圆形光斑、横向亮带及柔化光晕，但未证明它们来自真实镜头、生成模型还是后期。可转用的是视觉关系与分布，不是某个插件名。

### 3. 观看位置使海接近身体
约0—5秒，视野贴近水面和人物脸，前景亮点、水波、头发与手交错。观看者不像远处参观一个摆姿的人，而像在同一水面附近。
约6—10秒，位置较低，近浪进入下缘，人物张臂/靠近；海不是一个退在远方的背景平面。
约11—15秒，双手从脸旁到镜头前，手在近处变大、变软，脸部明朗且有表情变化。0.2秒间隔的取样可看到手势阶段及前景遮挡，不把它缩成一个固定伸手姿势。13.8秒附近脸的上部也被画幅/遮挡部分切走，说明“每帧必须完整露眼口”不适合作为通用标准。
约24—27.8秒，坐姿回望、转开、抬腿与水花前后相继。它给画面实际的时间变化，而非只靠静帧上水珠。未逐帧验证全部身体/水接触，因此不据此断言物理模拟正确。
约40—43秒，近处虚化绳索、人物与后方水面亮点组成前中后景；光、衣料和转身共同建立空气感。

### 4. 段落变化保持了环境亲缘
| 约略区间（秒） | 取样实际看见 | 可吸收的问题 |
|---|---|---|
| 0—5 | 短发眼镜近脸、贴水面、手、水与高亮散斑 | 怎样让观看者进入人物所在的环境 |
| 6—10 | 低观看位置、浅色衣料、近浪、展开手臂 | 海水、身体与画幅下缘怎样互动 |
| 11—15 | 编发造型、双手靠近、嘴眼反应与脸近景 | 动作阶段与观看距离怎样改变亲近感 |
| 16—20 | 较长发、海边转身/张臂、逆光与倾斜视野 | 衣料、发丝、地平线如何共同形成身体感 |
| 21—27 | 眼镜坐姿、水边腿部变化、回望与水花 | 生活动作怎样让海成为实际活动空间 |
| 28—31 | 倾斜构图、全身或较完整腿部、近浪 | 如何用全身与地面关系补足近脸段落 |
| 32—35 | 风中的短发、低头扶发、海面亮点 | 小动作如何支撑柔和人物气质 |
| 36—39 | 水面附近后仰的侧面与暖亮反光 | 静一点的姿态与大光比如何并存 |
| 40—43 | 栈道/栏杆、近处绳索、张臂转身 | 环境构件怎样参与层次而不只是填空 |
| 44—48 | 眼镜与扎发造型、扶发、笑与回头 | 近景怎样留下自然变化 |
| 49—尾 | 草帽、白衣、海面与扶帽/扶发 | 道具、斑驳光与脸部如何统一 |

区间是取样定位，不是逐镜精确切点；片内没有据此建立一个完整人物故事。其组织更偏同类海边体验的多个片段。音乐决定剪接的说法没有本轮证据。

### 5. 用户喜欢的点：确定与待确认
确定：用户特别喜欢这个作者此片的画风、风格和视觉效果。
待确认但有依据的解释：可能喜欢风格化人物处于真实可感的光与空气中、近距离观看、轻盈活跃的身体反应，以及浪/风/衣料让环境进入人物生活。用户没有逐项确认这些解释，不能据此认定只喜欢海边、眼镜、女性、泳装、某种脸型或持续对镜头笑。

## 三、图1：清新来自亮度组织、简洁大形与轻盈线条

### 可见构成
白发、很大的深色眼睛、简化鼻口与圆润面部，人物/画幅呈明显斜向关系。背景主要是明亮蓝天及少量模糊形；白发与白衣占大面积，黑眼睛、睫毛、领口等集中形成暗部。头发有大的带状发束，也有轻细弧线向外伸出。

### 它做得好的地方
1. **白色有层次。** 白发里仍能看见偏冷的阴影、发束交叠和较亮边缘，白衣也有折面；明亮不完全等于抹掉体积。局部亮处可能接近纯白，不能称全图没有任何高光损失。
2. **大面积浅色里有清楚的暗部锚点。** 眼睛、睫毛与领口稳住注意力。其清新不等于每个地方都低对比，更不等于整幅去掉黑色。
3. **皮肤很简洁，但有柔和色变。** 鼻颊、眼下有浅粉与软阴影，使面部仍有圆润体积；无需毛孔即可形成柔和材质感。
4. **发束疏密与方向赋予轻盈。** 有大面积流线，又有细弧线与空隙，蓝天能从间隙显露。它不需要每根头发都具有同样精细的写实纹理。
5. **背景让位。** 蓝天承托白发和脸，少量虚化形提供距离，细节密度集中在主要人物。
6. **近距离与斜向构成有活泼感。** 不能仅凭单帧认定原片有具体摇镜或真实风力，但静态已经有贴近和轻盈的方向性。

### 对“光质感”的具体解释
这张可分为高明度整体、浅色物体的灰阶层次、柔和肤面过渡、较清楚的眼部反光、蓝天/白发的色彩关系，以及有区别的清晰度。单说soft lighting会遗漏这些相互关系；一律加bloom可能糊掉眼睛和发束。

### 边界
用户明确选的是光与清新，尚未确认大眼幼态比例、白发、黑白衣着或倾斜构图是必选。把这张的全部角色属性写入后续提示词会超出已知偏好。

## 四、图2：精致来自形体、层次与材质分工

### 可见构成
较正面的头肩肖像，粉发与紫色虹膜，面部较图1修长，鼻梁、眼睑、唇形和肩颈结构更明确；深灰绿背景安静，服装也较暗。脸部和粉发承担主要亮度，发饰以金属感边缘与局部反光作小面积强调。

### 它做得好的地方
1. **发型有三级组织。** 先是头顶到肩部的整体轮廓，再是相互穿插、卷转的发束，最后才是顺着发束的细线。大量细节服从总体形状，不是均匀铺满细丝。
2. **面部有细微的结构过渡。** 上下眼睑、眼窝、鼻侧、颊与下颏的体积可分；鼻、唇附近柔和变化使面部细而不只是一块光滑面。
3. **不同材质有不同光泽。** 肤面大体柔，嘴唇有较小而亮的反光，眼睛反光集中，发束有带状光泽，饰件更硬亮，衣服亮度较克制。细腻也来自这些差异。
4. **小范围精细颜色丰富。** 粉发、紫眼、肤面微暖、背景灰绿以及左侧少量冷色边缘形成层次，没有依赖所有部位高饱和。
5. **背景克制，为精细部位留空间。** 若把背景也加满机械、灯点、花草，现有发丝和眼唇细节的权重会改变。
6. **风格化造型与立体明暗兼容。** 比例依然经过美化和提炼，细致不等于必须增加摄影式毛孔、瑕疵或年龄细纹。

### 对“细腻”的具体解释
可以分开选择：几何结构细腻、发束组织细腻、材质反光细腻、颜色变化细腻、边缘处理细腻。它们与图像尺寸不同；仅写超高清或8K并不能规定这些关系。

### 边界
图中皮肤与发丝的视觉效果不能证明用了特定次表面散射、毛发系统、渲染器或底模。用户喜欢精致质感，不等于已确认偏好粉发、紫眼、女性角色或此服装；图2也不能单独确定完整头身比和动作风格。

### 已确认、候选与未知
**用户明确：** 动画/3D风格训练方向；视频整体风格与视觉效果；图1清新光感；图2精致细腻；个人审美还需继续补充。

**候选解释：** 喜欢设计过的人物与可信立体光感共存；喜欢细节有主次、背景适度让位；可能喜欢近距离、轻盈、可感的空气与环境联系。这些需通过后续对比确认。

**仍未知：** 具体人物形体比例、可接受的表面光滑/人偶感程度、室内与暗景喜好、环境复杂度、故事与纯气氛的侧重、运动夸张程度、偏好的声音与节奏。

不能从三个样本推成“只喜欢明亮、白皮肤、特定性别或清纯角色”。此前用户也喜欢《海的背面》暗青绿、安静且有织物感的结果，说明偏好可能随作品意图变化，不应将今天的清亮感升为全项目唯一规则。

## 六、可怎样用于下一轮创作
### 路线A：清新、有现场感的动画场景
保留人物形体提炼，采用图1的清亮层次，参照视频让环境通过前景、光、衣料/身体关系接近人物。适合下一轮检验“人物身处环境”的感受。风险是过多光晕/散斑会遮动作，过度可爱化会改变原人物处境。

### 路线B：精细、有材质分工的CG场景
人物结构与发束接近图2的精细度，服装/皮肤/发/布景分别分配光泽，再放入具体环境。适合检验细节能否服务整体。风险是把肖像展示移入场景后只剩漂亮脸，或全画面平均加细节而失去焦点。

二者都可以借视频的观看关系，无需复制视频角色身份、服装或动作。当前推荐先确定场景与观看距离，再决定角色提炼程度，随后细化材质；不能先要求极简人偶鼻口、又要求完全自然的同一张脸。

### 对《海的背面》的条件性转用
若下一张仍沿用该题：可以把维护者做成动画/3D风格成人，参考视频的光怎样落到头发、衣料和手上，保留图2那样的材质分工，并用图1的清亮关系减少整体灰闷。海景布仍须有画面正面、折边、裂口与同一浪纹的联系，工作动作保持可读。

视频里的真实水花、湿衣、全身舞动与对镜头嬉笑不直接套入修补场景。用户要的海边感可以通过模拟海边光、海景的前景延续与观看位置形成，是否进一步改变现实/幻象的边界需用户决定。新风格提案未获选、未出图，不把它称为已验证可融合。

## 七、怎样继续补充得更全面
建立观察地图，每次只补最有帮助的一两项，不要求一次准备完整资料库。

| 需要了解的维度 | 合适的参考 | 我来分析的问题 |
|---|---|---|
| 全身比例与轮廓 | 一张喜欢的完整人物图 | 头身、肩髋、手脚与服装轮廓怎样提炼 |
| 环境与空间 | 一张喜欢的完整场景，人物可很小或没有人物 | 空间密度、建筑/自然形体、远近空气与主体地位 |
| 光的适用范围 | 同时给喜欢的日景与夜景/室内景 | 喜欢明亮本身，还是特定的柔和过渡、亮部或色彩 |
| 材质精细程度 | 同类角色中一张喜欢、一张觉得过塑/过硬/过糊的图 | 哪种光泽、表面纹理、边缘和细节尺度越界 |
| 人物状态 | 喜欢的表情/动作片段或静图 | 松弛、专注、张扬、亲近等感受怎样被动作支持 |
| 画面组织 | 喜欢的远景/中景/近景 | 喜欢观看者离人物多近，能接受多少遮挡与留白 |
| 时间与声音（以后做视频时） | 一段最喜欢的具体片段 | 动作、停顿、镜头变化、声音如何共同作用，须实际听看 |

**下一批最值得补的三类**：完整场景、完整人物、一张不太喜欢但与喜欢图接近的对照。前两类补足当前参考大多集中脸部的缺口，第三类帮助界定“细腻到什么程度”“明亮到什么程度”。用户不必先用术语描述；说“喜欢光、不喜欢脸”“喜欢头发、不喜欢衣服”就足够作为分析入口。

每个参考只需逐步记录：来源、喜欢的具体部分、暂不采用的部分、适用的创作与待核项。一件作品可以贡献光线参考而不成为人物造型参考，也可以在不同项目中承担不同作用。
