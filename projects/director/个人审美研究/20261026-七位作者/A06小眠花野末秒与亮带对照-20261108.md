# A06 小眠《花野》的末秒与低位人物对照

补看 59.31–60.65 秒三处主画面，实停 61.095573 秒，播放器时长 61.141337 秒。三处均可见左侧发白的云体、右上卷起的暗云和底部靠近中心的小人物。前景暗下来，人物背后的较亮地面继续露出一线，发与衣的轮廓保持可辨。播放尝试曾循环到 3.73、7.50 与 11.23 秒，三图只用于回看前段，并未记成末尾。最后约半秒没有独立采样，原声及连续运动仍待核。 [原发布](https://www.douyin.com/video/7686213907261705487)

个人审美上，末秒保持了近地小人和巨云同框，我偏好保留地面的一线亮度来稳住方向。通用制作上，与小眠相关作的巨型电话、蓝熊不同，这个比较用的是人物和地面的明暗相接。继上次尺寸实验，本次画了两张原创对照，固定人物比例、姿态、位置与云团，只改变低处地面带的像素值。初稿同时把亮带改得偏黄，亮度和色彩混在一起。修订后两版地带分别为 RGB 61、65、64 和 145、149、148，三个通道都加 84，人物中心像素保持 38、41、42。全部差异落在横坐标 130–479、纵坐标 205–229。已打开修订图检查，右图的人物躯干边缘比左图更易读，但头顶仍和暗面相接。图板和渲染脚本可复现这组差异。 [修订图板](A06低位人物明度对照-20261108/contact.png)

这组只检查静帧中人物能否从近邻亮带分离。自然光材质、运动和首次观看者的识别仍需另测。《慢下来》续读点仍为 46.342330 秒。
