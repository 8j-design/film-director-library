# A01 第5集：第二次交棒，猫的眼神并不总领先

来源：[keshi&挑食猫第5集原发布](https://www.douyin.com/video/7681139704313466089)现有本地副本。视觉逐帧实读 9.166667–12.833333 秒，111连续源帧，7板；与上批重叠1帧，0–12.833333秒合计386个连续帧位置。未听音、未按原速验证，也没有测观众先看谁。

| 源帧时点（秒） | 实见 |
|---|---|
| 9.166667–9.233333 | 浅发手仍近胸，随后手到眉上方；深发回抱臂，猫大致居中朝前。 |
| 9.400000–10.200000 | 浅发保留抬手形状，深发仍抱臂；猫在这段中从近正面转向画左、靠浅发的一侧。 |
| 10.233333–10.400000 | 浅发手经面前下落、抱臂并在画面中变大，背景、猫台与右侧人物维持相对位置；不能只凭成片判定是角色推进、单层缩放还是其他制作法。 |
| 11.033333→11.066667 | 浅发从占左前景跳回靠左中景尺度、闭眼抱臂；右侧深发约11.30先收肘，11.40抬两手、11.43已见双V与笑。 |
| 11.43–12.83 | 猫约11.63闭眼、稍后回到近正面，再约12.07向右侧转；深发持续双V与轻微上下变化，12.63收手、12.73手到面颊。 |

修正上批“交棒就看角色出入”的窄判定。9秒这次确有交叠；11秒下一次则是浅发缩回并抱臂，之后深发做新动作，中间有约三分之一秒。猫由左转回、再朝右，发生在右侧角色动作已经建立之后，故在这里有延迟的回应；不能推广成猫总是报幕。**个人审美**：保留两位表演者低幅错开，中央猫仍有独立节律。**通用能力**：把接替者起势、退场者收束、旁观者反馈做成三条动作轨。可用同一原创构图做旁观者抢先、同步、延迟三版，顺序打乱让读者判断第一注意对象及何时完成交棒，分别记行动清晰度与喜好；本批完成原作校正，三版验证未做。下次从12.833333秒起向后继续，直到接上此前后段的真实覆盖，再补原声和整段原速。
