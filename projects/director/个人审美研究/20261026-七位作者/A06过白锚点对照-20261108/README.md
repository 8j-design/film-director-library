# A06 原创过白转场锚点对照

小眠原作约 54.80 秒可见蓝城里的透明球，61.50 秒附近出现近白，63.21–68.97 秒的空间里仍可见透明球，墙和天空位置改组。把连续物体的辨认从原作的色彩、动作和声音中拆出来，试片用橙廊道、蓝房间、简化人物和一枚带斜纹的圆章。 [前一段原作实读](../A06小眠独舞听筒与过白转场-20261108.md) [后一段原作实读](../A06小眠球室落点与眼部转接-20261108.md)

每轮两版各 3 秒，24 帧/秒。第 29 至 32 帧为同样的暖白画面，帧号从零开始。保留版的圆章斜纹延续，改动版在过白后镜像翻转斜纹。各轮内部固定圆章位置和大小、人物轨迹、画面其余元素和白场长度。第一轮把圆章钉在中心附近。对照板显示这个版本给了两版一个很强的固定坐标。第二轮让圆章在过白前从左下接近画心，过白后继续往右上缓移，两版共用这条路径。两轮之间也改变了位置运动，比较首看辨认结果时应先比较同一轮内的两版。

实际编码并解码四条片，各为 72 帧。逐帧比对编码前图像，每轮两版前 33 帧逐像素一致，后 39 帧的差异限制在圆章的斜纹范围。回看解码图板，两轮都能在过白后辨出圆章和变动的斜纹，第二轮在末两帧样本之间有小幅位移。斜纹反向也可能被看作同一物件旋转或反射发生变化。若观众在两版都认作同一枚，应先检查斜纹是否足够独特，再考虑换成不易由旋转解释的标记。还缺第一次观看的辨认反馈，也未核声音或原作闪白持续时间。后续可分别问观众是否进入新空间、认出什么延续物，再收是否觉得圆章相同。 [验证记录](metadata.json) [生成脚本](render.py)
