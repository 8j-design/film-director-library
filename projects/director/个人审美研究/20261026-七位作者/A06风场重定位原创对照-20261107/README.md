# A06 原创试验：遮挡后重新找到人物

从小眠原作约 43–55 秒先后见到暗衣附近的近中远人影、暗区里的低可见人影、开阔亮地和更容易辨认的人形。这里复用的是“遮住再交代位置”的剪辑问题。云和人物都是程序绘制的自制图形。

| 版本 | 第 36 帧解除遮挡时 |
| --- | --- |
| A | 不改原景别。 |
| B | 切到 1.43 倍近景，人物仍在画面约六成宽处。 |
| C | 同 B 放大倍率，画面左移，人物到了约八成宽处。 |

三版 3 秒、24 fps、无声，人物、地形、形体动作和遮挡解除帧相同。每个 MP4 已完整解码到 72 帧；实际对读编码后的第 35、36、52 帧。35 帧三版都看不到人物；36 帧都能看到。A 中人物小、但右侧云体完整，B 中人物更容易在对读时分辨，代价是云体顶部被裁；C 中人物更靠右，云体被顶边和右边切掉，远景关系变得不同。B/C 是同一倍率但不同取景的对照，变动也带走了背景线索，因此不能只把两者差别归给人物移动。

这批只验证画面差异确实存在。主控已经知道人物位置，接触表也能停留，不足以说明初看者更快找到了谁。遮挡前没有先看清人物的阶段，这批测试的是显露，仍不足以检验“找回同一个人”。下一轮在遮挡前先给短暂可见的斜姿人影，恢复后保持原地形两处地标在框内，再比较位置匹配和移位，用首次指出人物时刻及错认作指标。回小眠相关作核对重定位是否真靠可辨认的空间线索。原作声画和具体生成流程继续单列。
