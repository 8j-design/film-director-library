# 从装饰图案研究到实际图像：本批验证了什么

这批接A05本人花纹墙教程，不是重新列片单。先把“纹样很多所以好看”修正为“建筑分区、大小与疏密、主角分配、光影与静区一起起作用”，再做真实图像检验。

| 实际产物 | 检验内容 | 结果与限制 |
| --- | --- | --- |
| V1/V2，原生SVG与PNG | 固定相机/建筑/人物/光影，只按墙面分区改纹样单元步长 | 尺度层级确实可见；尺寸与密度联动，不能分别归因 |
| V3，图后修订 | 保留其余元素，去掉中央行走带的地面网格 | 脚边竞争变少，但出现规整跑道感；仍是简化示意 |
| I1，原创插画 | 把上述方法转到一个有完成度的天文台庭院 | 大小纹样/纵深/人物尺度可见，但旧化噪声过多、偏废墟写实 |
| I2，以I1编辑 | 减旧化与碎物，提蓝色反光 | 体块更清楚；多变量同时变化，材料/亮带歧义尚存 |
| I3，以I2编辑 | 把弯曲亮带明确为浅色石材铺路 | 石缝/边界和跨路投影改善材料辨识；未证明整体风格与动态能力 |

主控真实看每张图后才写结论并修订。独立审查实际看几何对照与插画，范围见独立视觉审查.md；未把提示词意图当生成结果。精确提示词三份、源码、参数和失败版全部保存。PNG是实际图像；SVG与Python是可改的局部试验源；没有第三方原图进入发布附件。

修后又回原教程02:48成图对照，并实际看Earle《睡美人》跃隙概念图、V&A拼砖；正文与阅读边界见经典与材料对照.md。它们揭示两处缺口：小人物的视觉地位必须跟动作任务一起决定；几何纹样的文化/工艺语义与无缝接缝不能用一个星形复制自动获得。

可以转用：做环境设定和静帧时，先看大形/主次，再分区安排纹样，给人物动作留可读区域，明确光影与材料边界。仍不能报通过：A05整套风格、人物形象、完整动画镜头/声音、物理光照、真实文化场景、全部作者/全部系列、观众偏好与原44组能力。下一步继续本人其他教程与过程，补海水草图—成稿—过程；再转七作者中尚未实读的原作和同系列，不将本局部试验当结项。
