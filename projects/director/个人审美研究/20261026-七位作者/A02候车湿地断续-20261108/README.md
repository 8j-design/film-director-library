# A02 雨后候车湿地断续 G、H

保留历史原创候车 F 图作为固定基线，复用同一房屋、两窗、人物、候车牌及路面上部。使用《泥泞》中先成形的断续暗积水和后加反光作观察依据。未用参考图的像素。 [旧 F 版与两轮记录](../A02-原创关系试验与两轮修正-20261027.md) · [《泥泞》原作实读](../A02泥泞与压力的亮纹方向-20261108.md)

- [G](G-shape.png) 把单块积水改成两块边缘有凹进的湿区和几处小湿斑。保留区沿用 F 的笔触及原位置。图板中路面露出的暗带让几块湿地可以分开辨认，部分缺口的折线仍硬。
- [H](H-reflection.png) 保持 G 的湿区、纹理几何和粉色反光，只在既有暖窗反射纹上降低局部亮度。图板可见左侧暖带从连续亮列变成几处相连但有衰减的段落。它更接近本次研究的问题，代价是远看暖窗与地面的对应稍弱。

两轮修改均输出实际图像，并与 F 同时回看。F 到 G 有 28,792 个像素变化，G 到 H 有 1,949 个，全部是旧有暖纹的局部色值。上部 267 行逐像素一致。这些检查验证修改范围，材质的物理可信度、观众辨认、湿地边缘微形及动态反射仍未验证。复现脚本需历史 F 图，工作区内已存在。 [三版对照图](comparison.png) · [生成脚本](render.py) · [核验](verification.json)
