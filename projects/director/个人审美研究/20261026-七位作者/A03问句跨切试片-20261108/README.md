# A03 问句跨切试片

《阿米拉·序》约 81.233 秒仍见市场宽景与问句。81.267 秒切至灰袍人的腰部，问句在新画面保留两帧，81.333 秒已看不到。《练习4》的圣堂曾在同一构图内保留近处的人和远处的追捕者，让看者有空间依据辨认两人的关系。两部原作提供了不同的做法，一处通过字幕跨切和构图先后分配信息，一处利用同框远近。 [《阿米拉·序》片尾逐帧核对](../A03阿米拉救护问答至片名-20261108.md) [《练习4》圣堂空间实读](../Mei练习4圣堂控制反转与六帧冲击-20261106.md)

另做三个原创几何试片，各 3 秒、30 帧/秒。固定宽景、近景、人物运动、字幕文案、字幕出现时刻和切点，只改变字幕进入下一画面的时长。首轮做 0 帧与 2 帧，用来复现相近的字幕退出时机。随后增加 8 帧作为差异更明显的对照，核查这种延长会不会压过新人物入镜。

[0 帧版](carry-00.mp4) · [2 帧版](carry-02.mp4) · [8 帧版](carry-08.mp4) · [解码抽帧对照](decoded-contact.png)

三条片均实际编码、解码，都是 90 帧。编码前逐帧比对确认，2 帧版仅第 43、44 帧的字幕矩形改变，8 帧版仅第 43 至 50 帧改变，帧号从零起算。已读解码图板，在 43 帧看见 0 帧版先退出，在 45 帧只剩 8 帧版保留字幕。本轮只核呈现和控制变量。三版没有声音，原作的问答声线、音轨过切和首次观看者是否误认说话人仍待核。后续首看时先请观看者复述谁发问、画面何时转向对方，再比较三版。 [可复现脚本](render.py) [验证记录](metadata.json)
