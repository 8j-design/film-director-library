# A05 原创漏拍试验

第 72 集的原画让舞者在前景，鼓手所在的后排仍可见，发布文案另写了漏拍。原创短片换成灯串下的夜市舞者与鼓手，测试怎样把静图与文案合在一起提供的事件，改写成可按时间发生的动作和声响。原作音轨此轮未听。 [第72集证据](../A05丰收节第72集舞者与鼓手-20261108.md)

| 版本 | 变量和复核 |
| --- | --- |
| [01 全景准拍](01-all-strikes.mp4) | 4 秒，24 fps，96 帧。鼓点设计在第 15、33、51、69、87 帧，舞者姿态与灯景沿用到另两版。 |
| [02 全景漏拍](02-missed-wide.mp4) | 第 51 帧约 2.125 秒不击鼓。鼓手眼睛偏向舞者，持槌手停在鼓面之上。与 01 同全景，编码前仅第 47–57 帧有图像变化。此处有声音和表演两项配套变化，尚未拆分其单独作用。 |
| [03 同声轨加反应镜头](03-missed-insert.mp4) | 在第 48–61 帧切入鼓手较近的构图。02 和 03 解码后的 PCM 逐字节相同，编码前其余画面也相同。第一轮近景裁掉鼓面下部，第二轮扩大取景到同时看见眼睛、持槌手与完整鼓面，再读解码图板。 |

第 51 帧起的 100 毫秒窗，三版 PCM16 峰值为 16156、0、0。该值说明目标漏拍确实写入输出音轨。重看最后成片抽帧，反应镜头增加了面部和槌的面积，也会暂时让主舞者几乎离开画面。对比 02 时可以检验是否需要这次强调。未实听音轨，也未由第三方首看。应分别记录看者何时察觉漏拍、认为什么原因，并核反应镜头是否打断舞蹈连续性。 [首轮裁切图板](comparison-before-crop.png) · [修订后的解码图板](comparison.png) · [生成脚本](render.py) · [数值核验](verification.json)
