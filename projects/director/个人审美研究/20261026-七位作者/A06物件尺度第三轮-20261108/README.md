# A06 物件尺度第三轮

小眠《花野》靠旗和坡面交代人物位置，《世界紧绷，也许我们该慢下来》用反复出现的蓝熊、卷线和巨型电话改变人物与环境的比例。已有第二轮控制遮挡解除后的人物横移。本轮从这些证据挑出另一个变量，在室内到室外的剪切前后保留橙色斜角盒、圆孔和白线，使用室外旗和行人作尺度参照。 [《花野》](https://www.douyin.com/video/7686213907261705487) · [《慢下来》](https://www.douyin.com/video/7701631196526038307)

初版与修订版各有两条无声视频。每条三秒，24 帧每秒，在从零计数的第 30 帧切换，切换前的两版渲染像素完全相同。室外机位、地标与人物保持一致，变化只在橙盒绘制区。成片都完整解码 72 帧，图板读了第 23 和 48 帧。初版巨盒右缘触到旗杆，轮廓与地标挤在一起，接触本身会成为额外提示。修订版把巨盒缩小，保留盒底位置，在图板上恢复了清楚的间隙。相比小盒，修订巨盒仍高过旁边的人形。两代图板均保留供回查。

个人审美上，更偏好物件在背景里有呼吸空间，能读出它的斜角和孔。通用制作上，这次把尺度与前景遮挡拆开了。实际核验覆盖导出的剪切、几何差异与静帧可读性。首次观看者能否认出同一物件、判断尺寸变化及产生梦境感，仍需无提示观看。可用两版先问认出什么，再问哪个物体相对人变大。原作原声、后段和制作工程另续。
