# A05 鸣泣哔哔画水过程第74集

原发布归在《平平无奇的变魔术作画过程！》第 74 集，播放器显示 42.98 秒。作者在发布说明估计作品画了约五小时。短视频剪辑的时长、图层次数和作者自述分别记录。相邻第 71–73、75–76 集本次只核导航。 [鸣泣哔哔原发布](https://www.douyin.com/video/7697250436826270976)

| 时段 | 实读到的图像变化 |
| --- | --- |
| 0.410、5.793 秒 | 白底稀疏线稿先给出横向人物、头和伸展肢体。到 5.793 秒已有青绿水色、白色反光和红衣大形，人体和头部仍留粗线。 |
| 8.02–8.93、12.01–13.06 秒 | 青水、红衣和灰暗面已能分辨，发面、眼部与局部亮色逐渐细化，水面可见松散色块。 |
| 16.01–17.15、20.00–21.06 秒 | 一次淡化状态把旧图压浅，能看见头发和角的细线。后一次见较干净的红衣平涂与轮廓，水面部分区域的白纹暂时少了。仅凭成片不知是图层隐藏、重绘还是视频剪接。 |
| 24.04–25.12、29.01–30.14 秒 | 人物大块明暗重新明确，白纹穿过靠水侧的红衣下缘、深色手臂和头发附近，胸口、肩部大色面大体完整。鱼状色块和水面亮暗开始分出前后。 |
| 34.02–35.15、39.01–40.34、41.80–42.98 秒 | 水线上下既有白纹也有偏黄绿亮纹，红衣上方仍有可读的实色褶皱。末窗保留成图并叠片尾互动图标，播放器随后循环至开头。 |

与作者旧成稿册第 3、4 页相比，两处都让红衣、青水、角与水线建立可辨关系。旧第 4 页以水线遮过部分眼部，新视频的横向人物大体保住眼与脸，水纹更多在衣、手、发附近承担叠压。两者同样保留大色块，读图重心各有取舍。和花纹墙教程对照，建筑内的图案依墙面区域和门洞疏密而变，水纹则依人物与水面的前后关系被截断或局部压上。已有 11 个真实读取位置，连续作画步骤、软件和图层设置、声轨、实际工时及是否用素材都留待证实。 [成稿册与色草旧读](A05-红黑色草与跨题材成稿-20261029.md) · [花纹墙](A05-花纹墙过程与图案层级-20261030.md)

个人审美候选是水中人物仍靠局部识别点站住，亮纹可以在前景很密而不必覆盖每块颜色。通用制作方法是先画无纹理时也清楚的大形，再分干区、没入区与反光区域。以原创系泊灯做四版，单独检查遮挡和反光色衰减。 [原创水面试验](A05水面遮挡试验-20261108/README.md)
