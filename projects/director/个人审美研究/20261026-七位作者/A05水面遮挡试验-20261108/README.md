# A05 原创系泊灯水面遮挡试验

鸣泣哔哔第 74 集的水纹可越过贴水一侧的衣、手与头发，同时给人物上方大形留空间。这里改为原创场景，一盏橙色系泊灯半没入水，左上以石岸和系绳给出位置。用相同水面、灯、绳、波线和相机位置，分别改波线遮挡、局部反光色和颜色衰减。 [原作笔记](../A05画水第74集从色草到水线-20261108.md)

| 版本 | 改动与实际图像比较 |
| --- | --- |
| [01](01-unmasked.png) | 让波线均匀盖过图层。浅纹穿过灯顶、灯罩和灯内，干区与入水区分界弱。 |
| [02](02-occluded.png) | 只在灯的干区遮掉波线。灯罩保持完整，底部仍被前景水纹切过。只有干区的 1,211 像素改变。 |
| [03](03-warm-reflection.png) | 固定同一遮挡和波线透明度，局部亮纹换成暖色。水面与灯发生颜色呼应，色带边缘齐，容易看成平行金条。 |
| [04](04-falloff.png) | 在同一反光区域改颜色权重，中心随纵向波动并向两侧、远处衰减。边缘比 03 弱，残留的直线感来自未改的波线形状。03 到 04 的 4,887 个变化像素都在原反光区。 |

图板实看两轮，后两版用同一组波线，因而可把边缘柔化和暖色面积变化归到颜色权重。原作水纹有不规则分叉、发丝穿插与鱼状暗块，这里的低细节灯形只检验局部层次。码头下缘仍有水纹穿过，水线固定，前后焦点也未做不同光照的测试。未验证流体真实感、观众是否读成部分浸水或与原作者成稿具有同等效果。 [四版实看图板](comparison.png) · [生成代码](render.py) · [像素核验](verification.json)
