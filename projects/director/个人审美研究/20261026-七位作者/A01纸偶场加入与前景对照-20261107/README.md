# 纸偶场的加入时机与前景大小

原作第5集先让两人举臂，猫稍后举爪，约16.53秒伏低，随后在箱沿附近迅速变大。原作第3集另有从画面下方进入大近景的组织。此处从第5集拆出两个变量，沿用此前原创工坊和小纸鸟的构思，以新绘制的简化造型测试构图与动作。[第5集](https://www.douyin.com/video/7681139704313466089) · [第3集](https://www.douyin.com/video/7682994627658468841)

每轮渲染四个2.5秒无声短片，24fps。两位制作者的动作、箱子、背景及纸鸟的结束时点保持固定。第18帧是两人动作起点，第26帧相差8帧，约0.33秒。启用前景变化的两个版本都从第33帧开始扩大，采用同一缓动时间。

| 版本 | 纸鸟翅膀起点 | 纸鸟前景变化 |
|---|---:|---|
| A | 18 | 无 |
| B | 26 | 无 |
| C | 18 | 有 |
| D | 26 | 有 |

第一轮第40帧，放大的翅尖与人物手部轮廓重叠。第二轮只把峰值从2.30倍减到1.72倍，留下各自手势的空隙。对比两轮接触表和原始渲染，在768×432画面第40帧，纸鸟翅膀像素与原人手轮廓的最短横纵距离由0变为32像素。第16帧四版一致，第23帧可分辨两种起点，第32帧扩大与不扩大仍一致，第40帧分出尺度差异。八个实际导出均解码为60帧。

个人审美偏向保留空隙的D版，因为它让小角色先参与、随后再扩大，同时两侧人物的手势还能读出来。通用能力记录为两个可分别修改的参数，以及放大前应检查接近的轮廓。第5集原作的角色尺度、动作和装饰可同时变化，这个无声测试只能检查被隔离的两项视觉变量。当前完成两轮制作者画面复核。下一步随机打乱A–D，记录独立观看者第一注意对象和哪一刻识别到纸鸟加入，再加原声参考的节拍对照。
