# A06 风场重定位第二轮

[上轮](../A06风场重定位原创对照-20261107/README.md)里裁切近景同时带走部分云体，且遮挡前没有先交代人物。这次借同作者相关作反复出现的蓝格布与蓝熊，给自制草场加入左旗和右石堆。前 16 帧先交代斜姿人形，窄遮挡物从左进入。第 36 帧撤掉遮挡，两版保持固定机位、人物大小、姿势和地标。matched 版人物在原位显露，shifted 版向右挪原始画布 122 像素。

两条 3 秒视频均完整解码 72 帧，实际对看编码后的 14、35、36、52 帧。两处地标在取样帧仍清楚，14 帧人物在两处之间，35 帧被挡，36 帧分别回到原位和更靠近石堆的位置。程序核对编码前前 36 帧逐像素相同，之后两版差异均落在输出画面的 x399–510、y249–274 范围内。这样可以把画面差异定位到人物的横移。前景板的外观、姿态和场面仍是示意，试片无声。已知目标的制作者静帧读图无法测量初看者的寻人时间。下一检验给观众播放随机次序的两版，收集恢复后首次找见的时间及是否认成同一人。
