# A06 小眠用蓝色手机串起两种空间状态

[《世界紧绷，也许我们该慢下来》原发布](https://www.douyin.com/video/7701631196526038307)。从 26.776352 秒续读五次离散截图，约 26.8–36.3 秒，实际暂停 37.004564 秒。

| 约时 | 可见事实 |
| --- | --- |
| 26.8–30.4 | 人物横卧蓝格床，手一度伸向床边，后见手里举蓝色按键手机。格纹床头、灯与墙面拼贴保持可辨。 |
| 30.5–32.2 | 手机出现在人物下方、近床面，手已在手机上方。离散画面不足以确认她抛、放，还是画面省略了中间动作。 |
| 32.3–36.3 | 较宽画面恢复水面样顶面，人物朝近处伸手，床与拼贴墙仍可辨。多个手机和电视悬在画面不同位置。前景蓝色按键手机由见正面到见背面，人物手在近旁。细线在图中可见，实际制作是否使用实体悬挂、合成或生成仍未知。 |

**个人审美。** 旧手机的颜色和按键轮廓同时出现在手持近景和悬挂画面，帮观众认回这个房间的日常材质。重复物换了位置和比例，空间才显得陌生。悬挂手机未能逐个验明是同一台。

**通用能力。** 前一批区分床窗等固定线索和会上移的蓝熊，这次蓝色按键机补了第二个会改变位置的重复物。拍自己的空间变化时，可以先用床窗让人认地方，再让日常物以不同尺寸进入前景，分别检验观众是否认得地点与物件。原创第二轮已经隔离人物横移，本批只回核作者原作，尚未制作这个移动道具变量。 [上一批卧室地标](A06小眠卧室地标与局部遮挡-20261107.md)
