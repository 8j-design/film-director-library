# A05 鸣泣哔哔第73、75集的遮挡与阅读位置

两条同属《平平无奇的变魔术作画过程！》。第 73 集时长 39.45 秒，读 8 个位置。第 75 集时长约 68.685 秒，读 12 个位置。片头、过程和近尾段均有实见位置，未覆盖连续操作和声音。 [第73集原发布](https://www.douyin.com/video/7693518096916696383) · [第75集原发布](https://www.douyin.com/video/7700901788718845211)

## 第73集 苹果堆把视线与手留给观众

- 3.185 秒白底草图先摆果物圆形、面部和两侧手。7.00–8.50 秒见红果大块、浅发红眼与深手。12.01–13.84 秒强暖光和暗面已经成形。17.01–18.70 秒图像被压浅，能看见发线和果物边界，无法判断具体软件或图层。
- 22.01–23.47 秒恢复深底和红果大明暗，浅发和红眼仍有识别性。27.00–28.62 秒果梗、耳饰、指尖等局部更清楚。32.01–33.51 秒出现细小发丝和点状高光。37.30–38.79 秒成图叠上片尾互动图形，停 39.223559 秒。
- 成果构图与旧色草和丰收成稿册第 2 页所记的果堆、双手和脸对应。本次增加的是过程与高光安排，旧底图不作为新增独立作品重计。作者发布文案给出角色嘴硬又想被邀请的内在愿望。仅看脸和手，画面可支持探看或等待，具体愿望主要由文案命名。此前原创门槛图的伸手姿态有类似歧义，若观众必须读成邀请，可以另试对方的可见反应、正反打或明确台词，再分别检验。 [原有色草与成稿记录](A05-红黑色草与跨题材成稿-20261029.md) · [旧邀请试片及复查](A05-门槛邀请试验-20261029/试验与修订.md)

## 第75集 拱洞把巨大观察者和小队列放在不同深度

| 时段 | 实见作画变化 |
| --- | --- |
| 2.676、7.00–8.77 秒 | 红草图先以一条地面线排出吹号小人和禽鸟，随后出现连续拱洞及带轮圆车。 |
| 13.01–14.51、19.02–20.45 秒 | 黄墙、红粉地先分开空间，轮车、鸟和远近圆形逐步铺色。早期拱洞内还能见浅色构图线。 |
| 24.00–25.73、30.00–31.60 秒 | 巨大面孔从较冷的拱洞内出现，人物面前保留队列和鸟车。后窗墙色由金黄偏向浅粉，格纹地面、轮影和局部亮道更明确。 |
| 36.02–37.54、42.01–43.66 秒 | 成图短暂呈现红底金边框，随后进淡化图与精线叠放的细化段。视频编辑有成稿插入，无法逐点推回真实绘制顺序。 |
| 47.01–48.40、53.02–54.33、59.00–60.45、66.02–67.52 秒 | 细化时可辨左上缩略参考、格纹地面及轮子，后段加入碎色和飞鸟形。近尾先见白底成稿展示，再见金色边框和片尾提示。停 67.950231 秒，末不足一秒未取到图。 |

作者的说明赋予外侧观察者和队列中的人物特定身份。只凭画面可确认脸在拱后、队列在走廊前层和车内还有人物，不能证明外侧和内侧角色是同一人。第 74 集以水纹叠压强调局部在水中，第 73 集靠苹果堆遮嘴留眼，第 75 集把拱柱作为较大的空间遮挡。共同点是先能分辨几个大轮廓，再在可读位置加局部信息。第 75 集的横向队列靠地面线和拱间空隙维系，不能从系泊灯试验的单一水线外推复杂构图已经验证。个人审美候选是偏好明亮密集画面仍有可以沿着看的路线。通用制作记录则是给前景遮挡明确任务，并区分画面能读出的行动和文案提供的身份。下一可看本合集第 72 集丰收节舞蹈过程，将文字中的节拍事件与实际插画和视频声音证据分开核。 [第74集画水实读](A05画水第74集从色草到水线-20261108.md)
