# A03 问句声音跨切试片

《阿米拉·序》问句字幕在切到灰袍人后仍留两帧，局部识别把对白结束定位到约切点前 0.25 秒。这是机器候选。当前会话没有可用的音频输入，原作对白残尾、环境声与片名过门仍留给实听。 [原作画面与机器定位](../A03阿米拉问答音轨与画面切点-20261108.md)

本试片固定上一版的 2 帧字幕和全部画面，用 Windows 本机合成与英文字幕一致的原创问句。三版都使用同一条录音，只沿时间轴平移。无配乐与背景声。第 43 帧为切点，帧号从零起算。先做在画面切换前结束的一版，再补切点结束、跨切结束两版。 [上一轮字幕比较](../A03问句跨切试片-20261108/README.md)

| 试片 | 解码后句尾相对切点 | 切点后 200 毫秒内的峰值，PCM16 |
| --- | ---: | ---: |
| [切前结束](voice-early.mp4) | −249.98 毫秒 | 0 |
| [切点结束](voice-flush.mp4) | +0.04 毫秒 | 104 |
| [跨切结束](voice-carry.mp4) | +200.00 毫秒 | 13917 |

三版解码后 90 帧逐字节一致。音频按同一振幅阈值测量，切点结束版残留两个样本略过阈值，不能据此说可听。三版开口也随整条声音平移，相对字幕出现的领先量不同。此轮验证能否在固定画面和字幕上独立放置声音，不判定哪一版更清楚。待真人首看记录发话者、答话者与切镜后听到的内容。每位观看者首次只看一版，再做比较，记录是否把问句归给新入镜人物。 [生成脚本](render.py) [解码验证](metadata.json)
