# A04 酩酊海底《骤雨》与《振翅》的局部到全景

两条同属《l2d堆堆》第 51、52 集，各实际读取 6 处。第 51 集发布页列三土为画师、酩酊海底为模型动画、犬为后期。第 52 集页面可核模型动画与后期的署名。角色和画师不从风格反推，三个项目的制作分工也不互相代用。 [第51集原发布](https://www.douyin.com/video/7513134880809553163) · [第52集原发布](https://www.douyin.com/video/7518330481508273449)

| 集与时段 | 实见组织方式 |
| --- | --- |
| 51，1.49、4.83、8.01–9.25 秒 | 暗底金色装饰围住多个小框，框内依次可见钟、带蝴蝶结的衣领和鞋。另有框与金色花形分布在边缘，画面把观众视线从物件引到人物。 |
| 51，12.00–14.47、16.00–18.18、20.01–22.46 秒 | 先见亮门口与远处人物、右边被裁的衣袖，继而见近处大朵紫花与右侧举持长物的人。末段将整体放进装饰框里，门口远人、前花和右侧人物同时可辨。播放器循环后停 1.489429 秒，最后一次截图窗早于时长 23.018005 秒。 |
| 52，4.74、8.01–9.20 秒 | 先以镜框内的正面与镜外背面建立关系。近处酒瓶、杯子和冷亮区可辨，后来有蓝色蝶状亮形，镜内面部旁出现抬起的手。 |
| 52，13.00–15.21、18.01–20.62、23.00–26.00、27.081 秒 | 先突出另一人物的脸和高亮布料，再拉开到镜、两人、桌与亮窗同在。最后一处眼睑变化可辨，亮形仍在不同深度。停 27.081301 秒，离媒体时长约 0.388 秒。 |

第 51 集把钟和鞋当成可独立读取的细节，之后再交代物件和人物的空间。第 52 集先让镜内和镜外互为参照，再用另一人物和亮窗扩充空间。第 50 集出现书本、伸掌及展示文字，第 51、52 集则把版式与空间揭示也纳入表演。原页署名和 Live2D 标签支持按动态展示研究，仍不能仅凭成片断言每层是拆分、遮罩、相机缩放还是后期组合。未确认手里长物的功能、镜像的物理一致性、逐帧路径与原声。

个人审美候选可区分第 51 集的深绿、紫与金框仪式感，以及第 52 集的冷高光和镜内外关系。通用制作上，先定一个读者能定位的物件，再用下一幅图把注意带回人物和行动。结合《双子生日》准备手和承接动作的旧证据，本轮修订原创找零 V4、V5，把注意从钱移到任务结束时的账册。 [第50集和同画师记录](A04-同画师第50集与拆分补画-20261030.md) · [原作接果与找零旧版](A04承接前的准备与原创找零-20261106.md) · [续修结果](A04找零注意与收束-20261108/README.md)
