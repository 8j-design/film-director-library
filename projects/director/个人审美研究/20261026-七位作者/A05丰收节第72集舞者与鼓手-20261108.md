# A05 鸣泣哔哔第72集 丰收节的舞者、鼓手和光带

作者合集显示第 72 集。播放器时长 51.455 秒。实际读取 11 处，含循环后回看开头。旧成稿册第 1 页已记白发角饰舞者、红裙、金色亮带和后侧橙发人物。本次增加过程证据，与旧成稿合并看，避免把同一构图重复算为新作品。 [第72集原发布](https://www.douyin.com/video/7691304498073046322) · [旧成稿册笔记](A05-红黑色草与跨题材成稿-20261029.md)

| 时段 | 实读的变化 |
| --- | --- |
| 1.19、1.94 秒 | 草图已建立举臂、躯干反向扭转、裙摆向右开展、后侧站人。草图未借色彩也能定位主轮廓。 |
| 6.01–7.42、12.00–12.93 秒 | 短暂显出亮而有运动模糊感的成图，再见压淡颜色和更清楚的前后线。成图预览先出现，视频时间不能直接当作实际作画顺序。 |
| 18.00–19.11、23.01–24.23 秒 | 线稿阶段后排逐渐展开，随后出现深背景、浅发、红裙、橙发人物与宽亮弧。此处可辨光带跨过局部裙面。 |
| 29.00–30.13、35.01–36.17 秒 | 一处取样让前景主舞者暂时消失，后排与弧光仍在。下一处舞者回归，红裙和浅发先可辨，少了一部分显眼亮粒。不能据此确认具体图层操作。 |
| 41.01–42.30、45.01–46.25、49.92–51.20 秒 | 亮粒和弧光在部分时刻更强，随后回到较清晰成图。末窗切到另一张红果近景与互动提示，不把片尾切换当成舞者构图的一部分。 |

作者文案写舞者令鼓手分神，鼓手漏了一拍后继续。画面能看到前景主舞者、后排对应人物与光带如何分配注意力，当前取样无法证明漏拍发生在视频音轨，也无法从静画唯一推断两人的心理。与第 73 集对照，那个近景主要用果堆遮挡、眼和手来暗示等待，这一张则靠主次人物和亮带让目光在场内移动。与第 75 集的拱洞和格纹地面相比，本集没有依同样的建筑边界组织观看，而是以人物轮廓和明暗控制前后。 [第73、75集对照](A05邀请与梦境游行第73和75集-20261108.md)

个人审美候选是明暗与色块可以先交代谁占主位，局部亮粒再加节奏。通用制作上，静图里可见的姿态与文案写的时序事件要分别验收。本轮用原创舞者和鼓手做成三条短预演，测试全景中的遗漏与反应插镜。源视频音乐、原画工程与实际观众辨认留待核验。 [原创漏拍试验](A05漏拍试验-20261108/README.md)
