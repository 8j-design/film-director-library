# A04《末班船·找零》注意与收束 V4、V5

V1–V3 已对接手时机和钱币接触后的归属做过修订，留下脸部和账册的问题。本轮沿用旧绘画、固定中景、币路径和接触时机。把酩酊海底相关作里可追踪的物件和人物注意，转成可在原创动作中检验的两个变化。 [V1–V3证据](../A04承接前的准备与原创找零-20261106.md) · [相关原作](../A04骤雨与振翅第51和52集空间递进-20261108.md)

| 版 | 修订 | 实际图板结果 |
| --- | --- | --- |
| [V4](v4-ferry-change.mp4) | 交接前至接钱后小幅变动两人的眼部。 | 解码局部图可辨 V3 的线条和 V4 新的眼点。在正常全景里的区别很弱，仍未证实看者会追到手。 |
| [V5](v5-ferry-change.mp4) | 保持 V4 的交接，再在 5.2 秒后让售票员把注意向账册移，并收手按到账册。 | 7.417 秒能看见手覆盖账册，较 V4 中仍伸在外面的手更能标出交易结束。看得出碰到账册，尚不足以断言记录已完成。 |

V4、V5 各 8 秒、24fps、192 解码帧，均为无声粗动画。复算 V3 的 192 个编码前原帧与历史保存的源帧逐像素一致。编码前 V4 与 V3 的差异限制在 0.75–3.65 秒间，V5 与 V4 的差异限制在 5.2 秒之后。图板取自解码片而非仅用输入图。这些对照验证改动时段和画面结果。观众对视线、工作结束与角色意图的理解，写实表演、材质和声音仍待实测。 [全景对照](comparison.png) · [解码局部对照](detail.png) · [复现脚本](render.py) · [核验记录](verification.json)
